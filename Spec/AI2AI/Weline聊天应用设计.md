# Weline 聊天应用设计

## 定位

Weline 是手机中独立于“魔女恶堕计划”组织 App 的日常通讯应用。它应像角色在世界里自然使用的聊天软件，观感接近正常聊天软件，可有少量二次元手游手机界面的精致细节。玩家首先看到会话、联系人和消息，剧情与变量在背后驱动内容；界面不展示协议、楼层或变量术语。

重构后不设置免责声明或首次说明。

## 信息架构与视觉

- 底部主导航为“消息 / 联系人 / 我的”。消息页展示头像、昵称、最近内容、时间和未读；联系人页提供好友申请、附近的人与好友列表。联系人页新增好友经“附近的人”进入角色名片后发送申请，不展示全部未加好友的内部账号。我的页面提供个人资料、余额与转账、账号与图片。
- 聊天详情保留左右消息、引用、长按、输入、扩展面板和明确的待发送确认。普通文字、语音、自定义表情、名片、位置、转账和历史红包按原有协议展示。
- 浅色以柔白、白色、深灰和柔和蓝紫为主；深色沿用相同视觉层级。轻圆角、细线和克制动效使其亲切、精致，与组织 App 的深紫酒红和契约氛围区分。
- 桌面图标为原创的单个消息窗和短线图形，名称显示 Weline。手机悬浮入口、桌面文件夹/Dock、内外通知、应用各页和无障碍名称保持同一显示名与视觉。
- 没有数据契约的现实产品仿真栏目不进入新版页面。玩家上传的头像和表情包仍可用，不引入已撤销的内置表情图片。
- 聊天输入栏使用清晰的文字输入区和可触控的语音、表情、扩展入口；表情面板可直达管理页。共享表情库在引入图片时确定唯一名称，账号从库中选用名称；user 账号选用后，聊天表情面板立即显示该表情。
- 表情管理独立于账号资料页。日常页以图片为主，只有范围、搜索、添加和整理入口；卡片不堆放动作与勾选框，点图进入详情，整理模式才出现多选。账号切换、图库分类和归档进入次级菜单。聊天添加直接选图并在原聊天完成预览、命名与保存；管理页和账号图库复用同一添加组件与导入责任层，单图不展示批量工具。已有名称、账号选用、历史图片解析和可恢复归档继续保留。

## 契约边界

“组织财务”使用专属 SVG 头像：复用组织 App 的 `WitchMark.vue` 标志，搭配深紫底与日元徽章；由共享 `WeChatAvatar.vue`
统一渲染会话列表、到账通知页和手机内外顶部提醒，不写入图片库或真实账号。

组织兑换的到账回执显示为“组织财务”只读通知会话，外观类似假好友和已到账的转账卡片；仅能阅读与返回，不能聊天、拍一拍、领款/退回、名片、建群、引用、转发或删除。假好友由独立通知记录派生，不是真实账号或好友，不参加普通聊天协议。兑换入口位于“魔女恶堕计划 → 商店 → 兑换”，Weline 钱包不承担兑换；未读和顶部提醒沿用 Weline 机制，阅读不结算钱。

聊天计算、处理规则与正文协议保持不变。`stat_data.手机.微信`、`Chat_On_WeChat`、`<WeChatLog>`、`<表情包>名称</表情包>`
和位置标签继续作为内部契约。内部应用 ID“微信”保持，保证旧 `magicGirlPhoneLayout`
桌面布局与旧存档直读；显示层统一为 Weline。

真实 SillyTavern 宿主中的手机尺寸、触屏、通知直达和变量时序仍需联调验收。
