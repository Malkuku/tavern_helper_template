# 变量卷轴快捷使用

「命运分歧」悬浮窗的技能与道具页签读取当前消息楼层 `stat_data.角色.user.技能` 和 `stat_data.角色.user.物品`。道具仅展示随身物品，不读取顶层 `仓库`。聊天、消息与 MVU 变量更新后重新读取当前楼层；数据缺失时显示空状态。

两页签直接渲染手机持有页的 `OwnedAssetCard` 与 `InventoryIcon`，沿用安全 SVG、技能和道具底纹、评级光效、数量徽记以及展开详情；卷轴只提供适合使用意图的操作区。

技能与道具条目展开后显示描述和作用。技能可直接点击“使用技能”；道具需选择 `1` 到当前持有数量之间的正整数，再点击“使用道具”。提交时再次读取当前楼层的持有数据与道具数量，过期条目和无效数量必须拒绝。

成功操作向酒馆 `#send_textarea` 追加一段 `<user>决定使用…` 与 `<list>` JSON 细节草稿，并触发 `input` 事件。技能细节包含名称、描述、作用；道具细节包含名称、使用数量、当前耐久、作用。原有未发送内容保留。入口不自动发送，也不立即修改技能、物品数量或耐久；使用效果与消耗由后续剧情及变量更新决定。未找到输入框时向用户显示错误，不消费意图。
