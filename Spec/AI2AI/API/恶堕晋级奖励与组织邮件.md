# 恶堕晋级奖励与组织邮件

## 奖励规则

主要角色和次要角色的魔法少女首次跨入恶堕等级 1～6 时，逐级发放恶堕积分。同一评级下，1～6 级每次晋级奖励相同：D=60、C=120、B=240、A=480、S=1100 点。评级取晋级角色的独立
`当前评级`，不取玩家评级。评级为空时暂缓发放；评级明确后补发尚未奖励的等级，已经发放的等级不因评级变动重算。非空但不属于 D/C/B/A/S 的评级视为数据错误，不结算奖励。

奖励按评级温和递增，低评级回报高于原先按同级任务倍数定价的数额，高评级回报相应降低。若角色从恶堕 0 级升到 6 级期间评级不变，六次奖励合计为 D=360、C=720、B=1440、A=2880、S=6600 点。

新开局以角色初始恶堕等级作为发放起点，不补发初始等级。新加入角色以加入时等级为起点。当前奖励只覆盖 1～6 级，若扩充更高恶堕等级，需先确定相应奖励规则。本功能不提供旧存档兼容。

## 数据与写入

`stat_data.手机.恶堕奖励` 为必填字段：

```ts
{
  已奖励等级: Record<string, number>;
  邮件: Array<{
    id: string;
    角色: string;
    评级: 'D' | 'C' | 'B' | 'A' | 'S';
    等级: number;
    积分: number;
    时间: string;
    已读: boolean;
  }>;
}
```

`已奖励等级` 的键为 `<角色类型>:<角色key>`，对每个角色只保存一个发放水位。每封邮件的 `id` 为
`<角色类型>:<角色key>:<等级>`。新开局组装直接写入初始水位和空邮件表；新加入角色在统一阶段结算前补入起点。统一阶段结算读取最新楼层，按水位发放每一级奖励，并在一次
`stat_data`
写回中更新等级、积分余额、发放水位和邮件。重入不重复发放；结算数据无效时不写入部分结果。聊天切换后的待处理写入沿用手机 Store 的取消语义。

## 信息界面

手机“信息”应用的组织收件箱展示奖励邮件，逐封显示角色、评级、阶段、已自动入账的积分、公司式鼓励文字和静态品牌 SVG。邮件未读时，手机悬浮入口与桌面“信息”图标（包括文件夹和 Dock）显示红点。打开某封邮件后，在最新楼层写回该封邮件的已读状态；该聊天全部邮件已读后红点消失。短信草稿功能保留在收件箱下方。
