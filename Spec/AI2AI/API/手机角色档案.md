# 手机角色档案与解锁

手机角色档案读取当前聊天最新楼层的 `stat_data`。桌面内部应用标识仍为“主要角色”“次要角色”，显示名分别为“心象监测”“人物观测”，旧脚本变量 `magicGirlPhoneLayout` 无需迁移。

## 我的档案

- 只允许编辑 `角色.user.基础信息`；当前评级、金钱和恶堕积分保持只读。
- 保存时重新读取最新楼层，写入最新楼层的 `stat_data`，触发 `mag_variable_update_ended`；聊天切换后取消过期操作，失败向页面显示原因。

## 角色观测

- 主要角色动态读取 `角色.主要角色` 的实际 key。心象、身体、档案分三页，默认进入心象页；切换角色时返回心象页。
- 心象页依次展示创伤稳定度、好感度、恶堕度；每项只读取 `描述[String(当前等级)]`。身体页只读取各部位当前等级对应描述，不展示其他等级。累积经验与当前状态可以显示。
- 主要角色基础信息、整体印象和三项当前等级表现免费。次要角色动态读取 `角色.次要角色`，概览页显示名称、在场和简介；档案页的性格与能力按字段解锁。列表不提前展示付费字段。
- 解锁价格参考“魔法少女恶堕/更新规则”中 D 级普通任务 3～6、高风险任务 7～10 积分和一级技能 20～35 积分的经济尺度：

| 主要角色 | 日常外貌 | 3 |
| 主要角色 | 魔法形态（正常） | 5 |

## 持久化与失败语义

- `手机.档案解锁` 是可选字段，旧存档缺失时视为未解锁。结构为 `{ 主要角色?: Record<角色key, string[]>, 次要角色?: Record<角色key, string[]> }`。新开局不必预填。
- 每次解锁在同一份最新 `stat_data` 副本中校验角色、字段与余额，然后扣减 `角色.user.恶堕积分` 并记录字段，最后一次性写回。已解锁字段不重复扣费；余额不足、字段非法或角色消失时不写回。
- 档案编辑、解锁和微信写入共用顺序队列，避免同楼层并发覆盖。余额与解锁记录只随聊天楼层存档，不放入全局或脚本变量。
