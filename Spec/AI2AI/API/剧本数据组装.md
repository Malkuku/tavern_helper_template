# 剧本数据组装契约

## 数据源

运行时数据来自当前角色主世界书中的以下禁用配置条目：

- `<开场白>配置`
- `<世界>配置`
- `<世界经济>配置`
- `<主线>配置`
- `<事件>配置`
- `<任务>配置`
- `<势力>配置`
- `<地图>配置`
- `<地图节点>配置`
- `<季节与节日>配置`
- `<开场文本>配置`
- `<种族>配置`
- `<角色>配置`

每个条目的正文必须是一个完整 JSON 文档。条目缺失、同名条目重复或 JSON 非法时，加载整体失败。

## 开场白与资源注册表

`<开场白>配置` 的根对象包含：

- `固定数据`：所有剧本共享的运行时状态基底。
- `开场白`：以 UUID 为键的开场白注册表。

开场白条目包含 `author`、`key`、`desc`、`可用`、`主题`、`图标`、`自定义主角` 和 `内容配置`。`内容配置` 是分类资源 UUID 清单：

- 单例引用：`开场文本`、`世界`、`地图`、`主线`。
- 集合引用：`角色`、`世界经济`、`季节与节日`、`势力`、`种族`、`任务`、`事件`。

未知字段或未知资源分类视为契约错误，不进行宽松猜测。

## 组装规则

- `世界` 与 `主线`：UUID 定位条目后直接使用 `entry.data`。
- 普通集合：UUID 定位条目，以 `entry.key` 为运行时对象键，以 `entry.data` 为值。
- `种族`：先以 `entry.type` 分组，再以 `entry.key` 为键写入 `entry.data`。
- `角色`：`type` 只允许 `user`、`主要角色`、`次要角色`；`user` 为单例，其余两类以 `entry.key` 为键。
- `地图`：读取地图条目的 `root` UUID 拓扑，再从地图节点注册表解析节点；每个节点以 `entry.key` 为键、以 `entry.data` 为内容，递归子级写入 `子地图`。
- `开场文本`：使用对应条目的字符串 `entry.data`，独立于 `stat_data`。
- `system.当前剧本`：组装时设置为开场白 `key`。
- 空集合引用合法，组装为空对象。

最终 `stat_data` 必须通过工坊结构预检，并由当前角色卡注册的 MVU schema 作为宿主运行时最终契约。

## 失败语义

组装是全有或全无操作。以下情况返回结构化错误，不输出部分结果，也不触发宿主写入：

- 开场白不存在或 `可用: false`。
- UUID 悬空或同一资源被重复引用。
- 普通集合、种族或角色出现重复运行时 `key`。
- 角色 `type` 未知或同一剧本引用多个 `user`。
- 地图拓扑存在缺失节点、重复节点或同级重复 `key`。
- 组装结果不符合运行时结构预检。

错误包含分类、相关 UUID 和可读说明。UI 只展示错误，不补全或跳过错误资源。

## 宿主应用

- 等待 MVU 初始化后，将组装结果写入最新消息楼层的 `stat_data`。
- 将同一楼层正文替换为开场文本。
- 写变量成功但消息替换失败时，必须尝试恢复原 MVU 数据；恢复失败必须显式报告。
- 独立工坊同时支持导出 `{ scenario, stat_data, opening_text }` JSON，不修改世界书资源。

旧式从单个世界书条目解析完整 `<VariableInsert>` 的剧本加载职责已被本契约取代。
