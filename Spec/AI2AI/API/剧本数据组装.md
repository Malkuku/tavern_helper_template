# 剧本数据组装契约

## 世界书数据源

运行时只读取 `<开场白>配置`、`<角色>配置`、`<地图>配置`、`<世界经济>配置`、`<季节与节日>配置`、`<势力>配置` 和 `<种族>配置`。

`<世界>配置`、`<开场文本>配置`、`<主线>配置`、`<任务>配置`、`<事件>配置` 已退出生产读写，不提供旧格式迁移或兼容分支。

## 剧本结构

剧本包装字段为 `author/key/desc/可用/视觉方案/自定义主角/内容配置`。`视觉方案` 只能是灯、铸、刃、冬、心、杯、蛾、启、破镜之一。

`内容配置` 直接保存初始 `世界` 对象、`开场文本` 字符串、`主线` 对象以及有序的 `任务`、`事件` `{ key, data }[]`。这些内容没有 UUID 或跨剧本共享语义。角色仍保存版本 UUID；地图保存唯一地图 UUID；世界经济、季节与节日、势力和种族保存自动同步的共享资源清单。

## 组装规则

组装器直接克隆剧本内世界和主线，把任务、事件投影为运行态名称键对象，并把开场文本作为消息正文。不得创建临时叙事注册表或 UUID 引用。

角色按 UUID 解析并携带 `meta`。同一 `type + key` 只能选择一个版本，且必须恰有一个 user。地图按唯一引用装配，其余共享资源全量装配。

缺失剧本、不可用剧本、地图或角色缺失、重复 user、同身份多版本、重复运行态 key、未知角色类型以及最终 schema 非法均显式失败。宿主写入保持 `stat_data` 与消息正文全有或全无。
