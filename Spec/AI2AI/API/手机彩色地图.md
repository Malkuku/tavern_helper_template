# 手机彩色地图

## 地图数据

- `stat_data.地图` 是以地点名为键的嵌套地图。每个节点包含 `图标`、`名称检索词`、`描述`、`详情`、`危机等级`、`危机描述`、`方位`、`子地图`。
- `图标` 是完整的安全 `<svg>...</svg>` 字符串。允许白名单图形元素上的十六进制、RGB/HSL 等安全颜色及 `currentColor`；可分别设置元素的 `fill`、`stroke`，形成多色图标。脚本、事件属性、外部资源和非白名单标签/属性拒绝进入新开局。
- `方位.x/y/z` 仍是各有两个数值的区间；以城市中心为原点，x 向东、y 向北、z 向上。手机地图以 x/y 区间中点投影节点，z 用于显示层次；节点重叠时复用尘史地图的避让算法。
- 角色卡 `系统配置/地图资源.json` 是当前开局的地图资产来源。示例采用城市、四个街区、学园区内一所学校；保留学园区、大学区、金融区三个角色区域检索 key。

## 手机展示

- 手机“地图”从当前楼层读取 `地图` 与 `世界.地图索引`，自动进入单根城市的子地图。点击节点查看描述、危机和详情；有子地图时可继续进入，通过面包屑返回。搜索覆盖全部层级。
- 当前地图索引与可见节点名称一致时标记当前位置。`世界.地点` 是更细的叙事位置，只在顶部展示。地图界面只读，不修改角色位置或旅行状态。
- 运行中的旧楼层若缺少图标或图标非法，单个节点使用默认定位图形；无地图数据时显示空态。安全 SVG 会保留自身颜色，手机视图不套用尘史的金色图标样式。
