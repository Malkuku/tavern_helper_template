# 组织技能商店

## 数据

`stat_data.技能商店`
以技能名为键，单项包含`图标`、`描述`、`作用`、`价格`、`评级`（D/C/B/A/S）。`角色.user.技能`使用同一字段结构，但`价格`是累计投入：新购为售价，同名升级后加上升级售价。初始赠送技能价格为 0。技能只保存当前完整效果，不保留等级表或历史版本。

玩家评级由任务领奖累计贡献决定，技能 `评级` 只表示自身强度。购买、同名升级、出售与叙事直接修改技能表均不改变玩家评级；门槛见[玩家评级与成长](./玩家评级与成长.md)。

`角色.user.技能栏位`保存已解锁容量，初始缺省时为 6，最多 20。第 n 格（7～20）消耗 `(n-6)×50` 恶堕积分，即第 7 格 50 点、第 20 格 700 点，每次只解锁一格。已有技能超过容量时保留已有数据，但不得购买新技能直到持有数低于容量。技能商店的“我的技能”页签显示持有数、容量、解锁入口和相关提示；资料页也显示持有数和容量。解锁从最新变量校验容量和积分，在同一次写入中扣费并增加容量；失败不改变变量。

沿用`系统.技能下次刷新时间`和`系统.技能主动刷新次数`。前者是手机脚本计价的周界标记，后者记录当前计价周成功刷新的次数；两者不用于触发 AI。世界时间达到下次周一时，脚本按次数 0 报价；下一次成功刷新时更新两个字段。商店货架跨周保留。

## 手动刷新

新开局由唯一开局固定数据提供 2 个初始货架技能，可直接购买；初始上架不消耗免费刷新次数。玩家手动刷新成功后仍以生成结果替换整张货架。

独立手机 APP 的刷新按钮发出
`Chat_On_SkillShop`，该事件对应的生成规则为`生成技能.ini`。宿主侧绑定状态不由本仓库判断，实际生成时序在酒馆中验证。规则输出一份`<skillVariable>{...}</skillVariable>`，生成目标为 6 个不同名称的技能；实际返回数量偏离目标时仍逐项校验，只上架有效技能。全无可用项时保留原货架且不结算。玩家有技能时，AI 应自选 1～3 个已有名称生成完整新版本，其余为新技能；持有技能不足 3 个时以上限为持有数量，没有持有技能时全为新技能。实际结果即使没有满足同名升级数量，也可上架。正常生成技能最高为玩家当前评级后一档，超限单项跳过；同名新版本由玩家按效果、价格和评级判断是否购买。

手机脚本只在本次按钮触发的生成期间读取 assistant 正文中最新的完整结果标签，逐项校验必要字段、金额和数量；无效技能不写入也不展示，多余字段不写入变量。缺失、不安全或不符合形状要求的 SVG 图标回退为默认图标，不阻断生成。至少有一项可用技能时，在一次变量写入中替换整个货架、扣积分、更新下次周一时间和次数；部分有效仍按一次刷新结算。串行队列中的后续重复事件会跳过；全无可用项不改货架、不扣费。失败标签由系统自动清理，暂时失败则后台重试，不阻断下次刷新。没有持久待刷新请求；脚本重载会取消尚未完成的刷新，玩家可重新点击。生成结果可以写回触发时的同一消息楼层；手机读取该楼层原始消息，与触发前的结果标签比较，只结算本次新增或变更的 assistant 结果。等待生成期间可手动取消；取消后忽略迟到结果，不扣费。

本周普通刷新报价按已成功次数依次为 0、5、10、15、20、20……恶堕积分，单次封顶 20；每周一 00:00 按世界时间重置报价。积分不足时不能刷新，不限制每周刷新次数。

玩家可输入希望出现的技能用途或风格，选择定向刷新。本次报价为普通刷新价额外加 50 点。手机在触发事件前将请求 ID、类型、要求与普通报价写入`手机.定向刷新`；`生成技能.ini`仅读取类型为技能的本次要求，将其作为提高相关结果出现机会的参考，不保证指定内容必出。成功上架时重新核对请求与报价，在同一次变量写入中扣总价、更新货架与次数、清除请求。失败或取消不扣费并清除请求；脚本重载后发现无活动生成的遗留请求时清除。普通刷新会先清除遗留请求，避免沿用旧偏好。

界面勾选“定向刷新”后展开偏好输入，原“刷新货架”按钮直接显示普通报价加 50 点并提交定向请求；未勾选时该按钮提交普通刷新。勾选但未填写偏好时不能提交。

手机在消息接收、消息更新及 MVU 更新完成后检查本次结果。全无可用项或写入失败时自动清理本楼失败的技能标签，暂时失败则后台重试；清理不阻断后续刷新，不要求玩家手动操作。清理只删除所定位的标签，不改动同楼其他内容。安全 SVG 支持常见图形表现属性，仍拒绝脚本、事件、样式和外部资源。

## 交易

购买时从最新变量中再次检查货架、余额和价格。新购把商店技能复制到玩家技能；同名购买覆盖完整版本，并把原累计价格与本次售价相加。购买后移除货架项，不改变玩家评级。新购技能还须有空闲栏位；同名升级不占用新栏位，满位时仍可升级。

可购技能卡片通过边框直接区分交易类型：新购使用等级色实线框，同名新版本在等级色框外增加紫色双层外框。技能评级直接展示在货架与已持有技能卡片上；不再保存数值型战力贡献。

出售从玩家技能中删除该技能，返还`floor(累计价格 / 2)`积分；确认前展示实际返还值。初始赠送技能累计价格为 0，出售返还 0。

变量卷轴提供已持有技能的快捷使用入口，仅把名称、描述与作用填入待发送聊天草稿，不在点击时修改技能；见[变量卷轴快捷使用](./变量卷轴快捷使用.md)。

购买、出售和刷新结算均使用手机 Store 的串行写入队列；聊天切换时放弃过期写入。真实生成时序需在酒馆中验证。

成功购买、升级或出售技能时在当前楼层正文追加一条
`<systemLog>`，记录技能名称和实际积分变化；失败时不保留本次记录。货架刷新不作为玩家剧情行动记录。成功解锁栏位时也追加一条
`<systemLog>`，记录新栏位数与积分消耗。
