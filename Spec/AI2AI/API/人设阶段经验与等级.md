# 人设阶段经验与等级规则

## 数据与职责

主要角色的 `人设阶段.创伤稳定度`、`好感度`、`恶堕度`，以及次要角色的 `人设阶段.恶堕度`，沿用
`{ 当前等级, 累计经验, 描述 }` 结构。这里的 `累计经验`
是**当前等级尚未结算的有符号经验余额**，可以为负；字段名沿用现有数据契约，不表示角色一生获得的经验总和。

对话规则按每轮已经发生的剧情，只修改相关角色、相关指标的 `累计经验`。手机脚本统一计算
`当前等级`，并扣除跨级所需经验。规则不直接写等级。没有实质变化的一轮记 0，不因对话轮数自然增长。

`描述`
的连续整数键决定角色实际可用的等级范围。计算公式不写死 0～6：有负等级或高于 6 的等级时，仍按相同公式计算相邻等级之间的需求。主要角色的三项范围可不同；次要角色目前只配置恶堕度。等级键不连续、当前等级缺少描述或经验无效时，脚本报告错误且不写入部分结算结果。

## 相邻等级的经验需求

`T(L)` 表示从等级 `L` 跨到 `L+1` 所需经验；反向跨过同一边界，也使用 `T(L)`。

| 指标       | `T(L)`                         |
| ---------- | ------------------------------ |
| 恶堕度     | `ceil(30 × 1.55^max(L, 0))`    |
| 好感度     | `ceil(16 × (1 + 0.25 × d²))`   |
| 创伤稳定度 | `ceil(25 + 120 × (q - 0.65)²)` |

好感度的 `d = max(abs(L), abs(L+1))`。创伤稳定度的
`q = (L + 0.5 - 最低等级) / (最高等级 - 最低等级)`，最低、最高等级取该角色稳定度 `描述`
的数字键；仅在存在相邻等级边界时计算。归一化后的 0.65 附近最容易变化，两端阻尼增大，下端阻尼更强。公式对不同等级范围仍适用，不要求角色一定是 0～5 级。恶堕度的高等级需求按指数增长，负等级若存在则使用最低一级的需求 30。

创伤稳定度表示角色采用的**心理应对模式阶段**，不是精神值百分比。等级升高表示逐步恢复更稳定的应对模式，降低表示认知、价值判断或行为逻辑逐步失衡；一轮压力不能仅凭“更痛苦”就直接解释成进入下一级模式。角色资源中四位主要角色目前均配置 0～5 级且从 5 级开始。例如索菲亚的 5 级是能接受拒绝、判断承受能力的「克制」，0 级是忽视敌我、请求与拒绝的「救济失控」。

在当前 0～5 级配置下，相邻边界的需求为：

| 稳定度边界 | 5↔4 | 4↔3 | 3↔2 | 2↔1 | 1↔0 |
| ---------- | --: | --: | --: | --: | --: |
| 经验需求   |  33 |  26 |  28 |  40 |  62 |

因此 4↔3 一带最容易变化，5↔4 仍需持续影响，1↔0 最难跨越。正向恢复和负向恶化跨同一边界使用相同需求。复杂程度留在曲线和脚本中，不让对话规则按当前等级乘倍率或判断特殊崩溃事件。

恶堕度 0→6 的六个需求依次是 30、47、73、112、174、269，合计 705。这个合计只用于感受节奏，运行时逐级计算和扣除，不保存累计门槛表。

## 每轮经验变化建议

同一轮按事件实际造成的状态变化结算相关指标，不按台词条数、回复长度、玩家单方面宣称或普通聊天叠加；不同指标可以同时变化。下表是三项指标共用的简单判断尺度，不让 AI 计算等级倍率、阈值或特殊事件倍率。脚本仍允许一次经验变化跨多个等级。

| 本轮实际影响 | 经验变化建议 |
| ------------ | -----------: |
| 没有实质变化 |            0 |
| 普通影响     |        ±1～3 |
| 明显影响     |       ±4～10 |
| 重大事件     |      ±10～30 |

这些是判断尺度，不是要求每轮得分或脚本的跨级上限。经验变化的正负方向以指标语义为准：好感度正值表示更亲近；稳定度正值表示更稳定的心理应对模式；恶堕度正值表示更深入恶堕。恶堕度经验允许负值，但等级不可回退。

## 跨级结算

在一轮的经验变化写入后，对每个阶段独立重复以下操作，直到不能再跨级：

1. 若 `累计经验 >= T(当前等级)` 且存在下一级描述，扣除 `T(当前等级)`，等级加 1。
2. 好感度、创伤稳定度若 `累计经验 <= -T(当前等级 - 1)` 且存在上一个较低等级的描述，加回 `T(当前等级 - 1)`，等级减 1。
3. 恶堕度不执行降级。其负经验保留为当前等级的欠账，后续正经验先抵消欠账，再可能升级。

两个方向都允许一次变化跨多级；每跨一级都按当时所在等级重新计算需求。结算后的经验余额可以为负。处于角色已配置的最高或最低等级时，不越过配置范围；超出端点而尚未结算的经验仍保留在该等级。

例：好感度 1 级、经验 0 时减少 25。`T(0)=20`，结果为 0 级、经验 -5。继续减少到满足 `-T(-1)`
时，可在同一轮或后续轮继续降到 -1 级。恶堕度 2 级即使经验跌为负数，仍保持 2 级，直到经验重新达到 `T(2)` 才升到 3 级。

手机脚本监听当前楼层 MVU 变化后，从最新楼层数据结算全部已有阶段；只有等级或经验余额实际变化时才写回。写回走手机 Store 的顺序队列并重新触发变量更新事件，下一次检查因结果已稳定而不再写入。聊天切换期间放弃旧聊天的待结算写入。旧存档的次要角色若缺少恶堕度，继续正常读取，不强行补齐。

恶堕等级提升后的积分与组织邮件由[恶堕晋级奖励与组织邮件](./恶堕晋级奖励与组织邮件.md)规定，并与阶段结算在同一份最新楼层变量中写回。
