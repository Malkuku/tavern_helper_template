# 手机仓库与物品技能图标

## 数据契约

- 首位目标选择时，向 `角色.user.物品`
  发放一件与目标对应、带专属 SVG 图标的 D 级身份凭证：鹭见凛为“青叶学园转学生证明”，雨宫雫为“孤儿院志愿者登记函”，索菲亚为“白鹭大学交换生证明”，小鸟游琉璃为“小鸟游琉璃私人助理工作证”。前三者提供进入相应公开场合、申请活动或报名的剧情依据；小鸟游路线直接确立已受聘的私人助理身份，允许在职责范围内随行和处理她交办的日常事务。凭证不自动完成接触任务，也不授予职责之外的权限。孤儿院活动仍须工作人员同意。同名规格冲突时拒绝发放。
- `角色.user.物品` 与顶层 `仓库` 均为以物品名为键的物品表。物品包含
  `描述`、`作用`、`评级`、单件基准`价格`、`数量`、`耐久`，可包含 `图标`；道具商店同结构。完整交易与生成规则见
  [组织道具商店](./组织道具商店.md)。
- `角色.user.技能`
  的每项保存当前完整版本，包含`描述`、`作用`、`价格`、`评级`，可包含`图标`和布尔字段`启用`。缺少`启用`的旧技能视为已启用。`价格`是购买和升级投入的累计积分；不保存技能等级与历史版本。商店技能不带`启用`字段，其`价格`为本次购买价。
- `图标` 为完整 `<svg>...</svg>`
  字符串，采用地图图标现有的 SVG 安全白名单校验：拒绝脚本、事件属性、外部资源和非白名单标签/属性。新开局校验 SVG；显示运行时数据时再次校验，非法或缺失时显示默认图形。运行时叙事写入的物品可缺图标。
- 技能与道具图标容器使用不同 SVG 底纹：技能为法阵圆环，道具为物资棱盒；资源自带图标叠放在底纹上，缺失或非法时分别使用星芒与提袋默认图形。持有页与商店页使用同一套类型视觉。
- 手机持有技能、随身道具与变量卷轴使用同一 `OwnedAssetCard` 展示条目；`InventoryIcon`
  负责图标、底纹和默认图形。入口各自提供使用或库存操作，卡片和图标样式由组件维护。
- 技能与道具条目在持有页和商店页默认收起，只显示图标、名称和必要的评级或数量；点击标题行才展开描述、作用与交易或库存操作。道具统一显示评级配色；持有及丢弃列表隐藏价格，商店购买区显示单价和所选数量的总价。商店支持购买和丢弃，技能仍可出售。切换商店分页或操作来源时收起条目并取消未提交的确认。
- 手机技能页中，已启用技能展开后提供“使用技能”，关闭技能不提供使用入口。点击时重新读取当前楼层持有数据，拒绝已删除或已关闭的技能；复用变量卷轴的使用草稿规则，将技能名称、描述和作用追加到酒馆聊天输入框，保留原有内容并触发
  `input` 事件。成功和失败均在页面提示；不自动发送或立即结算效果。缺少`启用`字段的旧技能仍可使用。

## 手机仓库管理

- 桌面仅保留“随身物品”入口，打开统一物品管理界面，默认显示随身库存。界面可切换随身与仓库两处库存、搜索名称、查看描述与作用、选择正整数数量存入或取出。旧桌面布局中的独立“仓库”图标在读取时过滤；库存数据不受影响。
- 选择转移先加入本地待确认变更，预览同步更新两处数量；撤销清空草稿。确认时按操作顺序，在当前楼层最新 `stat_data`
  副本上逐项验证，再一次性写回。
- 转移以物品名为键。目标同名且规格相同时保留目标图标、累加数量、按两边数量加权平均耐久并向上取整；规格不同则拒绝合并。目标没有时复制来源元数据。来源归零时删除条目。来源不存在、数量不足或数量无效时整体拒绝写入，错误显示在页面；草稿保留供用户撤销或重试。
- 手机 Store 的串行队列负责与档案、微信写入排序，并在聊天切换时取消过期操作。页面收到外部变量更新时撤销尚未提交的草稿。
- 确认一批库存转移成功后，在当前楼层正文追加一条
  `<systemLog>`，按提交顺序记录存入或取出的道具及数量；草稿、撤销和失败操作不记录。
