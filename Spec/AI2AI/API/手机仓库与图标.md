# 手机仓库与物品技能图标

## 数据契约

- `角色.user.物品` 与顶层 `仓库` 均为以物品名为键的物品表。物品包含 `描述`、`作用`、`数量`，可包含 `图标`。
- `角色.user.技能` 的每项包含 `当前等级`、`等级表`，可包含 `图标`。
- `图标` 为完整 `<svg>...</svg>` 字符串，采用地图图标现有的 SVG 安全白名单校验：拒绝脚本、事件属性、外部资源和非白名单标签/属性。新开局校验 SVG；显示运行时数据时再次校验，非法或缺失时显示默认图形。旧存档可缺字段。

## 手机仓库管理

- 桌面“随身物品”“仓库”两个入口打开同一个管理界面，分别预选对应库存。界面可切换两处库存、搜索名称、查看描述与作用、选择正整数数量存入或取出。
- 选择转移先加入本地待确认变更，预览同步更新两处数量；撤销清空草稿。确认时按操作顺序，在当前楼层最新 `stat_data` 副本上逐项验证，再一次性写回。
- 转移以物品名为键。目标同名时保留目标元数据并累加数量；目标没有时复制来源元数据。来源归零时删除条目。来源不存在、数量不足或数量无效时整体拒绝写入，错误显示在页面；草稿保留供用户撤销或重试。
- 手机 Store 的串行队列负责与档案、微信写入排序，并在聊天切换时取消过期操作。页面收到外部变量更新时撤销尚未提交的草稿。
