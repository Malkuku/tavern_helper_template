# 手机仓库与物品技能图标

## 数据契约

- 首位目标选择时，向 `角色.user.物品`
  发放一件与目标对应的 D 级普通道具：鹭见凛为“青叶学园公开事务简报”，雨宫雫为“基础缝补工具包”，索菲亚为“便携急救包”，小鸟游琉璃为“公开市场资料夹”。道具作用只提供公开信息或普通实物支持，不自动完成接触任务；同名规格冲突时拒绝发放。
- `角色.user.物品` 与顶层 `仓库` 均为以物品名为键的物品表。物品包含
  `描述`、`作用`、`评级`、单件基准`价格`、`数量`、`耐久`，可包含 `图标`；道具商店同结构。完整交易与生成规则见
  [组织道具商店](./组织道具商店.md)。
- `角色.user.技能`
  的每项保存当前完整版本，包含`描述`、`战力评级贡献`、`作用`、`价格`、`适用评级`，可包含`图标`。`价格`是购买和升级投入的累计积分；不保存技能等级与历史版本。商店技能字段相同，其`价格`为本次购买价。
- `图标` 为完整 `<svg>...</svg>`
  字符串，采用地图图标现有的 SVG 安全白名单校验：拒绝脚本、事件属性、外部资源和非白名单标签/属性。新开局校验 SVG；显示运行时数据时再次校验，非法或缺失时显示默认图形。运行时叙事写入的物品可缺图标。

## 手机仓库管理

- 桌面仅保留“随身物品”入口，打开统一物品管理界面，默认显示随身库存。界面可切换随身与仓库两处库存、搜索名称、查看描述与作用、选择正整数数量存入或取出。旧桌面布局中的独立“仓库”图标在读取时过滤；库存数据不受影响。
- 选择转移先加入本地待确认变更，预览同步更新两处数量；撤销清空草稿。确认时按操作顺序，在当前楼层最新 `stat_data`
  副本上逐项验证，再一次性写回。
- 转移以物品名为键。目标同名且规格相同时保留目标图标、累加数量、按两边数量加权平均耐久并向上取整；规格不同则拒绝合并。目标没有时复制来源元数据。来源归零时删除条目。来源不存在、数量不足或数量无效时整体拒绝写入，错误显示在页面；草稿保留供用户撤销或重试。
- 手机 Store 的串行队列负责与档案、微信写入排序，并在聊天切换时取消过期操作。页面收到外部变量更新时撤销尚未提交的草稿。
- 确认一批库存转移成功后，在当前楼层正文追加一条
  `<systemLog>`，按提交顺序记录存入或取出的道具及数量；草稿、撤销和失败操作不记录。
