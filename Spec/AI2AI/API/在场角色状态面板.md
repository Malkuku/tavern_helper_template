# 在场角色状态面板

## 入口与职责

- `src/在场角色状态/index.ts` + `index.html` 是独立消息楼层前端，产出
  `dist/在场角色状态/index.html`，通过酒馆助手消息楼层前端方式嵌入。
- 手机优先，一次查看一位在场角色；角色选择器区分同名主次角色。阶段/身体两页切换；切换角色回到阶段页并收起身体详情。
- 直接复用手机 `ObservationStageContent.vue`、`ObservationBodyCard.vue` 和
  `witch.css`。两个入口共用卡片 DOM、状态条、配色与身体交互，独立入口仅调整楼层外框。
- 独立面板通过 `data-observation-theme="refined"` 使用 `witch.css`
  中的观测主题变体：顶部显示运行态头像、角色名与评级；阶段标题统一，状态条置于描述上方，相邻预览与奖励保留。柔和底色、细边线和身体详情样式同样由此主题维护；手机默认观测主题不变。
- 只读变量，不初始化世界书、不结算阶段、不扣费、不修改解锁记录。阶段结算与交易仍由手机 Store 负责。

## 数据与显示

- 读取 `getCurrentMessageId()` 所在楼层的 MVU `stat_data`，历史楼层不读取聊天最新状态。
- 遍历主次角色，仅纳入 `在场 === true`；不按已发现目标筛选，不把缺失在场字段解释为在场。
- 主要角色显示创伤稳定度、好感度、恶堕度；次要角色显示好感度、恶堕度。当前等级、描述、无数值经验推进/回退条、相邻等级预览和恶堕晋级奖励提示全部由手机组件负责，不另行定义经验曲线或预览方向。
- 创伤稳定度免费；其他阶段和身体状态沿用
  `手机.档案解锁[kind][角色key]`。未解锁时不渲染值与正文，提示到手机观测解锁，不新增交易路径。
- 身体页沿用手机：特殊状态直接展示，四部位当前状态以卡片依次排列，点击部位头同时展开特征和开发程度。切换角色或页面后收起详情；空字段提示未记录，不推断身体健康。
- 长文本保留换行、自然折行，不自动摘要、不截断正文；随聊天滚动，无内部滚动容器、固定视口高度或 `vh` 高度。

## 刷新与生命周期

- 等待 `Mvu` 初始化，监听 `VARIABLE_INITIALIZED`、`VARIABLE_UPDATE_ENDED` 和
  `kat_mvu_update_finished`，重新读取所在楼层。
- 当前角色仍在场时保留选择；离场或删除时回退到列表首位；无人时显示空态。
- 读取失败清空旧快照并提供重试；无角色数据与无人在场分别提示。
- `pagehide` 卸载 Vue 并释放监听，初始化等待期间卸载后不注册迟到监听。

## 验证边界

- `scripts/validate-present-status.cts`
  使用真实 Vue 编译、渲染与事件，覆盖共用手机组件、状态条、回退/满条、身体展开、解锁隔离、角色切换、缺字段、重试与卸载。
- 窄屏视觉验证使用合成数据，不将样例高度作为业务文本长度上限。
- 真实角色正文、手机酒馆 iframe 与事件时序仍需宿主联调。
