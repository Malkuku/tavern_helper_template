# 微信正文增量与手机交互

## 数据与会话

`stat_data.手机.微信` 是微信权威数据，类型见 `src/手机界面/types.ts`。账号保存当前好友关系；`会话.消息[]` 按顺序保存普通消息与操作。消息没有 ID。私聊 key 是 `私聊:<账号A>&<账号B>`，包含 user 时 user 在前，否则账号 ID 稳定排序。群聊 key 由创建事件提供且必须唯一；展示名称可重名。微信界面只列出成员包含 user 的会话，通讯录由 `账号.user.好友` 派生。

好友申请、通过、拒绝、拍一拍、创建群聊、邀请进群都作为操作项进入消息流。申请会创建私聊；待处理状态从该私聊最近一轮申请及处理操作推导，拒绝后可再次申请。新群先只有创建者，后续按顺序邀请好友。非好友不能发送普通私聊消息；群成员只能邀请自己的好友。正文与界面共用写入前校验。

## 发送与正文协议

用户发送消息时，Store 写入 `{ 会话, 时间, 内容, 引用? }` 到 `准备发送` 并触发 `Chat_On_WeChat`。时间取 `世界.时间`。正文确认前不向会话追加消息；待发送内容保留，可重试。已有待发送、未初始化、无有效世界时间或不符合好友关系时明确报错。

主动和后台规则在 assistant 正文中输出 `<WeChatLog>{"事件":[...]}</WeChatLog>`。事件数组按发生顺序原子应用，事件类型为 `消息` 或 `操作`。由第一条普通消息创建新私聊时提供 `会话信息`；好友申请操作可直接创建私聊。创建群聊事件必须提供唯一会话 key、创建者与展示名称，同一日志后续事件可沿用。消息 `内容[]` 可含文字、语音、表情包、红包、转账、名片字符串标签及转发对象；引用是消息顶层内容快照字段，不使用消息 ID。

领取红包、收款、退回转账会追加操作项，供会话展示行为提示，同时更新原消息的 `特殊内容状态[内容下标]` 供卡片展示。同一发送者同一时间有多条符合条件的款项时，选择最近的未处理项。当前没有金额结算契约，这些动作不修改角色金钱。第一版不支持撤回或退群。

Store 在消息接收、更新和生成完成后检测当前 assistant 楼层，解析全部日志并一次应用；校验失败不写入部分数据，也不清空待发送，并在微信页面显示失败原因。首条事件若与待发送的会话、user、内容和可选引用一致，且正文时间不早于待发送时间，就确认发送并清空缓冲。待发送时间取发送时的世界时间，正文聊天时间可以向后推进，不要求世界时间同步变化；确认后保存正文中的实际时间。年月日允许不补零，比较时规范化；时间格式无效或早于待发送时间仍报冲突。重复日志使用聊天变量 `magicGirlWeChatAppliedLogs` 的楼层签名与已应用状态检查避免重放。同楼层正文继续追加日志时，若旧事件仍是新事件序列的完整前缀且旧事件仍在变量中，只应用新增事件；旧事件被改写时继续报冲突，避免重复应用。聊天切换后的过期任务不能写入新聊天。手机未打开时，只要手机脚本运行，Store 仍监听正文事件。

连续发送时，若楼层签名尚未记录、但本次待发送消息前的旧事件已完整存在于微信变量中，同步器跳过这段旧事件，再以本次 user 消息确认待发送内容。旧事件缺失或与变量不符时不跳过，继续报告冲突；不能把历史 user 消息当成本次发送来比较。

## 界面

2026-09-26 截图参考更新：聊天扩展面板只提供转账和名片发送，红包发送入口移除；历史红包仍可读取和领取。长按消息弹出仅含“转发”“引用”的菜单；引用预览显示在新消息气泡下方。名片卡片展示账号头像、昵称及“个人名片”。转账使用独立金额输入界面，消息卡片为橙色。

微信提供会话、聊天、通讯录、好友申请和个人账号页面。普通文字、语音、表情包、历史红包、转账、名片、引用、转发与消息流操作有各自展示；群聊显示成员。同一消息的 `内容[]` 各项按顺序显示为独立消息行，每项各有头像和气泡；例如两个文字项显示为连续两条消息。引用附在首项消息的气泡下方；长按菜单中的引用和转发针对被点击的单个内容项。聊天扩展面板可发送转账、名片；语音入口可填写转写内容和时长。历史红包和转账卡片可打开详情，收取者可领取红包、收款或退回转账，同一款项只能处理一次。点击对方头像可拍一拍；群聊详情可邀请好友。名片可打开账号资料并发起聊天或申请。发现页展示截图中的入口。

四个主标签使用用户提供的微信截图作为布局基线。手机脚本作用域的 `darkMode` 布尔变量控制明暗主题，通过 `getVariables({ type: 'script', script_id: getScriptId() })` 读取；未设置时为白天模式。无数据契约的入口点击后显示“暂未开放”。聊天详情显示头像、左右气泡、时间分隔、输入栏与表情或扩展面板；待发送且宿主正在生成时显示输入动画。手机应用界面提供 Home 按钮返回桌面。

表情包初始为空。用户选择本地图片并命名后，图片写入当前楼层 `手机.微信.账号.user.表情包[名称]`；重复名称或无效图片不写入。脚本变量 `magicGirlWeChatStickerSnapshot` 保存 user 上传的表情包备份；上传需等待备份成功再报告完成。读取楼层变量时恢复缺失的备份图片，且备份不覆盖楼层中同名的现有表情。
