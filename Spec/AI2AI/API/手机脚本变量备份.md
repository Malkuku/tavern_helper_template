# 手机脚本变量备份

手机“设置”中的备份作用于当前手机脚本的完整脚本变量表，不包含聊天变量、消息楼层 `stat_data` 或其他脚本的变量。

- “保存到酒馆本地”把 JSON 快照写入酒馆助手全局变量，键为
  `magicGirlPhoneScriptBackup:<脚本 ID>`。同一脚本只保留最近一次本地备份，其他全局变量不受影响。
- “导出当前变量 JSON”从当前脚本变量即时生成文件；本地备份和文件使用相同的
  `format: magic-girl-phone-script-variables`、`version: 1`、`scriptId`、`createdAt`、`variables` 结构。
- 可以从当前脚本的酒馆本地备份或导入的 JSON 文件恢复。文件来源脚本 ID 只用于提示，不限制迁移到另一个脚本 ID。恢复前要求确认，并以备份变量表完全替换当前脚本变量；关闭并重新打开手机后刷新界面缓存。
- 无法读取、保存、序列化或解析时显示失败，不把失败当作成功。该功能不会自动备份。
