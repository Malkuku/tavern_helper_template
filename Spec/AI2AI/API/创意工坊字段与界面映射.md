# 创意工坊字段与界面映射

## 用途与证据边界

本文是创意工坊固定领域编辑器的设计依据，不改变现有数据契约。本次已核对：

- `scenario/types.ts` 与 `scenario/schemas.ts`；
- `worldbookSource.ts`、`assets/repository.ts`、`assets/package.ts`、`assets/model.ts`；
- `scenario/assembler.ts` 与 `assets/runtimeRole.ts`；
- 当前 `DeveloperWorkspace.vue`、`UserWorkspace.vue`、`StructuredValueEditor.vue` 与 `App.vue`；
- Beta 配置目录 `O:\St Working\角色卡开发\尘史使徒\尘史使徒Beta\配置` 中的十三类真实 JSON 样本；
- 运行时类型 `src/尘史使徒/UI/types/StatData.d.ts`。

核对结论：Beta 样本与 `StatData.d.ts` 可共同确定十二类资源的领域字段。当前工坊 Zod Schema 仍只约束外层，因此实现时要保留样本中的字段类型和动态业务集合，不能将“固定领域表单”误解为删除技能、物品、人际关系等按名称建键的合法业务集合。

## 分类领域字段映射

“条目集”是按业务名称建键、子字段固定的记录；允许增删改业务条目，不允许增加契约外子字段。字符串默认 `""`、字符串数组 `[]`、数字 `0`、布尔 `false`，可选字段在原数据不存在时不主动写回。

| 分类 | 字段路径 | 业务名称与控件 | 校验/列表摘要/引用 |
| --- | --- | --- | --- |
| 世界 | `data.时间/地点/季节/天气/地图索引` | 时间与环境；单行文本 | 均为字符串；时间保留现有自定义格式；摘要为地点+时间；地图索引是运行时名称而非 UUID |
| 世界 | `data.危险场景` | 危险场景；开关 | 布尔；列表状态徽标 |
| 世界经济 | `data.名称检索词[]/区域检索词[]` | 检索词；可排序标签列表 | 字符串数组；摘要显示区域 |
| 世界经济 | `data.物价.{类别}[]` | 物价分类条目集；类别名+可排序文本项 | 样本含基本生活品、中级消费品与服务、贵族消费品与奢侈品；保留其他现有业务键；摘要显示类别/项数 |
| 世界经济 | `data.平均收入.{人群}` | 收入条目集；人群名+收入文本 | 字符串值；摘要显示人群数 |

| 主线 | `data.{主线名}.描述/警惕度/详细[]/已交融的魂质[]` | 描述多行文本、警惕度数字、两组可排序文本列表 | `描述` 字符串；其余为可选字段 |

## 派生展示与动作映射

- “可玩/待修复”、引用数、缺失引用、被引用次数、地图节点数、包内分类数量和真实差异摘要均是派生展示，不写回资产。
- 新建、复制、删除、强制删除及清理引用、保存、重新读取、选择导出、全量导出、包安装和角色加入均有现有能力来源。
- 不得在原型中增加自定义字段、任意数据类型、持久化历史、云端同步、自动保存或未有实现支持的“自动修复”。

## 实施注意

- Beta `任务` 注册表为空，但 `TaskData` 已给出完整形状；实现后用 fixture 做无损往返验证。
- Zod Schema 未细化 `data`。本轮不改契约；表单依真实样本与运行时类型实现，保存仍由现有外层 Schema 和组装预检兜底。
- 主线、技能、物品、语料、人际关系等动态键是领域条目名，不是任意自定义字段；其子字段必须固定。
