# 创意工坊字段与界面映射

## 产品边界

正式工坊只有“角色”和“剧本”两个创作领域，不再把底层注册表分类暴露为并列编辑器。UUID、注册表、共享 UUID 清单和资产包重映射是素材管理内部机制。

- 可创建与编辑：`user` / 主要角色 / 次要角色，剧本元设置，初始世界状态，角色组装，开场文本，主线，任务和事件。
- 只读自动装配摘要：地图、世界经济、季节与节日、势力、种族。界面不提供这些分类的创建、编辑或选择控件。
- 地图是 `author, desc, data` 包装的唯一完整嵌套地图；`data` 直接是组装器消费的最终内容。正式界面不存在地图资产或地图节点选择器；剧本初始地点可以通过完整地图的地点选择器写入 `地图索引`。

## 正式交互模型

- 2026-09-17 用户确认：正式工坊采用面向创作任务的角色档案工作台与剧本编排工作台，替代将全部字段纵向铺开的长表单。现有 `RoleEditor.vue` 和 `ScenarioEditor.vue` 的长表单结构是待取缔实现，不作为新版界面基线。
- 角色档案以头像和身份摘要作为稳定入口，主体按概览、人格关系、能力技能、状态物品和语料等领域切换；动态集合使用卡片、条目编辑器或详情面板承载。
- 创作者工作区中的角色档案默认可编辑，不设置没有真实权限意义的阅读/编辑切换。关系、技能、特殊状态和物品使用尘史运行时同一套双模式组件，在原布局中完成新增、修改和删除，不建立外挂编辑器。
- 原位编辑只修改同一份内存草稿，不逐字段持久化，也不绕过现有差异审阅和原子保存。运行时查看与工坊编辑共享组件结构、样式和图标，由 `view/edit` 模式决定控件。
- 角色选择使用独立交互式选择器：支持搜索和类型筛选，先选择角色身份，再在二级区域互斥选择具体版本，同时提供角色详情、版本差异、已选阵容和明确的确认动作。该选择器优先作为剧本组装的权威入口，并可供后续角色阅览和运行时加入复用。
- 剧本编辑以自由编排工作台为主。概览首先展示剧本身份、可玩状态、当前阵容和叙事骨架；角色、世界状态、开场、主线、任务和事件作为可进入的模块。首次创建可以提供辅助向导，但向导不形成第二套数据或编辑流程。
- 桌面端使用主工作区与上下文详情面板；移动端沿用相同信息架构切换为全屏分步页面，不将桌面多栏简单纵向堆叠。
- 参考同类产品只采用信息架构和交互模式，不复制与尘史视觉、现有数据契约或宿主环境不相容的皮肤和功能。

## 剧本映射

| 界面分区 | 字段 | 交互与规则 |
| --- | --- | --- |
| 元设置 | `key, desc, author, 主题, 图标, 自定义主角, 可用` | 文本、多行文本和开关；引用不完整时保存会保持不可用。 |
| 初始世界状态 | `内容配置.世界` 指向的 `data.时间/地点/季节/天气/地图索引/危险场景` | 在剧本内直接编辑；每个新剧本创建独立世界资产。`data.地图索引` 是运行时地点名，不是 UUID。 |
| 角色组装 | `内容配置.角色[]` | 同一角色身份（`type + key`）的版本互斥；选择另一版本替换当前引用，不追加覆盖链。所有 `user` 资产之间也互斥，必须恰有一个 `user` 才可玩。 |
| 开场文本 | `内容配置.开场文本` 及所指 `data: string` | 大型多行文本，保留 `<user>`、`<options>` 等标记原文。 |
| 主线 | `内容配置.主线` 及动态主线条目 | 条目子字段为 `描述/警惕度/详细[]/已交融的魂质[]`。 |
| 任务 | `内容配置.任务[]` | `key` 与 `data.描述/目标/阻碍/期望奖励/取得成果[]`；引用有序。 |
| 事件 | `内容配置.事件[]` | `key` 与 `data.描述/作用/进度`；引用有序。 |

新建剧本同时创建私有的世界、开场文本、主线、任务和事件资产。作者可显式改选既有叙事素材；选项必须显示已引用剧本，修改会影响所有引用者。既有共享引用不自动拆分。

角色版本互斥已于 2026-09-17 实现。交互式选择器按角色身份展示具体版本，选择新版本替换当前引用；存量覆盖链在进入编辑时归并为原先最后生效版本，替换引用不删除角色库中的其他版本。

## 角色映射

`type` 只取 `user` / 主要角色 / 次要角色。类型转换前显示将删除的不适用字段。角色档案工作台按领域组织：

| 领域 | 字段 |
| --- | --- |
| 基本资料、外貌与背景 | `key, author, desc, type`；`user.key` 恒为只读的 `user`；主要/次要的 `姓名/名称检索词[]/区域检索词[]/在场`；`user`/主要的 `年龄/当前身份/外貌[]/背景[]`；主要的 `当前想法/外貌概括/战斗风格[]/语料`；次要的 `简介/性格标签[]`。 |
| 视觉元数据 | `meta.avatar/meta.color/meta.avatarStyle?`；头像接受 URL、SillyTavern 本地资源路径或上传/截图生成的 data URL，并提供预览。空头像按角色 key 稳定生成默认样式，也可从六种样式中固定选择。主题颜色使用六位十六进制值，仅用于主要角色特殊对话框。 |
| 性格与关系 | `性格.社交表现/行动逻辑/思维习惯/人际距离/道德底色`；`人际关系.{对象}.认知了解/情感羁绊/利益纽带`；`性经验`。 |
| 基础数值与生命 | `基础数值.力量/敏捷/智慧/魅力` 和 `生命状态.{生命|体力|精神}.最大值` 由 Beta `MvuZod.js` 根据术等级派生，只读展示；仅 `生命状态.{生命|体力|精神}.当前` 可编辑。 |
| 技能与术 | `技能.{名称}.性相/技能等级/描述/消耗/作用`；`术之等级.{性相}.等级/经验`。 |
| 特殊状态与物品 | `特殊状态.{名称}.描述/效果/持续时间`；`物品.{名称}.类型/品质/描述/作用/数量/耐久`；`user` 的 `金钱/缥缈异质`。 |

动态集合按业务名称建键，支持新增、删除、复制、排序和折叠；子字段仍是固定契约，不是任意 JSON 编辑。读取—保存—重读必须保留未知合法字段、原类型和集合顺序。

## 派生展示与运行时

- 筛选标签由 `type`、`key`、名称/区域检索词、作者、剧本引用和运行时存在状态派生；不持久化 `tags`。
- 同 `type + key` 角色聚合为一个“角色身份”，二级版本抽屉默认收起；具体版本显示作者、引用剧本、字段差异及选定剧本的当前生效版本，UUID 不作为普通标题。
- 桌面端将保存状态、引用检查和当前对象收为常驻摘要条；当前角色头像、类型、作者、引用剧本、具体版本以及自动装配统计仅在展开详情时显示。移动端“检查”面板直接显示完整详情，不以抽象规则说明代替当前对象。
- 运行时候选默认隐藏已存在的同 `type + key`，`user` 按单例执行同一规则；用户可取消勾选查看已有角色。玩家工作区不提供派生标签筛选。
- 三类已有角色均在覆盖前显示字段差异并二次确认；确认后整体替换，取消不写入，失败恢复原数据。
- 保存审阅显示资产和字段级差异；所有运行时写入保持全有或全无。
- 移动端开发工作区使用“资源 / 编辑 / 检查”三个互斥面板；选中或新建资产后进入编辑面板，草稿计数、保存入口和主世界书连接状态持续可见。
- 角色域提供 AI 生成草稿入口，收集角色类型、用户创意和可选提升词。生成资产使用同一角色编辑器，不增加 AI 专属持久化字段。

## 格式边界

开发者资产包工具仍可导入、导出底层锁定资源，但不形成普通用户编辑入口。只接受 v2 资产包和 `data` 完整嵌套地图；v1 资产包、地图 `root` 拓扑及 `<地图节点>配置` 均明确拒绝。
