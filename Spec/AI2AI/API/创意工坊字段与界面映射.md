# 创意工坊字段与界面映射

## 产品边界

正式工坊只有“角色”和“剧本”两个创作领域，不再把底层注册表分类暴露为并列编辑器。UUID、注册表、共享 UUID 清单和资产包重映射是素材管理内部机制。

- 可创建与编辑：`user` / 主要角色 / 次要角色，剧本元设置，初始世界状态，角色组装，开场文本，主线，任务和事件。
- 只读自动装配摘要：地图、世界经济、季节与节日、势力、种族。界面不提供这些分类的创建、编辑或选择控件。
- 地图是 `author, desc, data` 包装的唯一完整嵌套地图；`data` 直接是组装器消费的最终内容。正式界面不存在地图节点、UUID 拓扑或地图选择器。

## 剧本映射

| 界面分区 | 字段 | 交互与规则 |
| --- | --- | --- |
| 元设置 | `key, desc, author, 主题, 图标, 自定义主角, 可用` | 文本、多行文本和开关；引用不完整时保存会保持不可用。 |
| 初始世界状态 | `内容配置.世界` 指向的 `data.时间/地点/季节/天气/地图索引/危险场景` | 在剧本内直接编辑；每个新剧本创建独立世界资产。`data.地图索引` 是运行时地点名，不是 UUID。 |
| 角色组装 | `内容配置.角色[]` | 可增删和排序。顺序是稳定契约；同 `type + key` 以后引用整体覆盖先引用。必须恰有一个 `user` 才可玩。 |
| 开场文本 | `内容配置.开场文本` 及所指 `data: string` | 大型多行文本，保留 `<user>`、`<options>` 等标记原文。 |
| 主线 | `内容配置.主线` 及动态主线条目 | 条目子字段为 `描述/警惕度/详细[]/已交融的魂质[]`。 |
| 任务 | `内容配置.任务[]` | `key` 与 `data.描述/目标/阻碍/期望奖励/取得成果[]`；引用有序。 |
| 事件 | `内容配置.事件[]` | `key` 与 `data.描述/作用/进度`；引用有序。 |

新建剧本同时创建私有的世界、开场文本、主线、任务和事件资产。作者可显式改选既有叙事素材；选项必须显示已引用剧本，修改会影响所有引用者。既有共享引用不自动拆分。

## 角色映射

`type` 只取 `user` / 主要角色 / 次要角色。类型转换前显示将删除的不适用字段。编辑器按领域组织：

| 领域 | 字段 |
| --- | --- |
| 基本资料、外貌与背景 | `key, author, desc, type`；主要/次要的 `姓名/名称检索词[]/区域检索词[]/在场`；`user`/主要的 `年龄/当前身份/外貌[]/背景[]`；主要的 `当前想法/外貌概括/战斗风格[]/语料`；次要的 `简介/性格标签[]`。 |
| 性格与关系 | `性格.社交表现/行动逻辑/思维习惯/人际距离/道德底色`；`人际关系.{对象}.认知了解/情感羁绊/利益纽带`；`性经验`。 |
| 基础数值与生命 | `基础数值.力量/敏捷/智慧/魅力`；`生命状态.{生命|体力|精神}.当前/最大值`。 |
| 技能与术 | `技能.{名称}.性相/技能等级/描述/消耗/作用`；`术之等级.{性相}.等级/经验`。 |
| 特殊状态与物品 | `特殊状态.{名称}.描述/效果/持续时间`；`物品.{名称}.类型/品质/描述/作用/数量/耐久`；`user` 的 `金钱/缥缈异质`。 |

动态集合按业务名称建键，支持新增、删除、复制、排序和折叠；子字段仍是固定契约，不是任意 JSON 编辑。读取—保存—重读必须保留未知合法字段、原类型和集合顺序。

## 派生展示与运行时

- 筛选标签由 `type`、`key`、名称/区域检索词、作者、剧本引用和运行时存在状态派生；不持久化 `tags`。
- 同 `type + key` 角色聚合显示变体数、引用剧本、顶层字段差异及选定剧本的当前生效变体；UUID 不作为普通标题。
- 主要/次要角色运行时候选先排除已存在的同 `type + key`，再执行搜索、类型和派生标签筛选。
- `user` 是运行时单例。覆盖前显示字段差异并二次确认；确认后整体替换，取消不写入，失败恢复原数据。
- 保存审阅显示资产和字段级差异；所有运行时写入保持全有或全无。

## 格式边界

开发者资产包工具仍可导入、导出底层锁定资源，但不形成普通用户编辑入口。只接受 v2 资产包和 `data` 完整嵌套地图；v1 资产包、地图 `root` 拓扑及 `<地图节点>配置` 均明确拒绝。
