# Weline 聊天应用视觉重构

## 状态

实现与本地验证完成；待 SillyTavern 宿主触屏、通知直达和视觉联调。

## 目标与范围

把手机中的现有微信式聊天 App 改为名为 **Weline**
的世界内日常通讯应用。整体观感接近正常聊天软件，可有二次元手游手机 UI 的细节。完整替换玩家可见的品牌、图标、页面结构与样式，覆盖桌面、消息、聊天、联系人、账号、款项、图片库、通知和浮层提示。

## 关键设计决定

- 不设置免责声明或首次进入说明。
- 保持现有计算与处理逻辑、数据模型、宿主协议、消息与支付规则完全不变；`stat_data.手机.微信`、`magicGirlWeChat*`、`Chat_On_WeChat`
  和 `<WeChatLog>` 等内部名称继续使用。
- 内部应用 ID 暂继续使用“微信”，保证旧 `magicGirlPhoneLayout` 布局与应用打开路径无迁移；所有玩家可见位置显示“Weline”。
- 日常通讯视觉与“魔女恶堕计划”组织 App 区分。主导航设为消息、联系人、我的；附近的人进入联系人页。移除仅模仿现实产品且没有数据契约的占位导航，真实功能入口保留。
- 图标和图形使用原创 SVG/CSS。已撤销的内置表情图片不得恢复；玩家上传的图片继续按旧路径显示。

## Agent 分工

- 当前 Agent：设计落地、实现、自测、文档收口。无独立测试 Agent；宿主视觉验收由可运行 SillyTavern 的一方完成。

## 验收标准

- 桌面图标、应用名称、内外通知、主导航、列表、聊天详情、联系人、账号、图片与表情、款项与相关弹层使用一致的 Weline 视觉，没有玩家可见的“微信”品牌文案。
- 会话、好友申请、待发送确认、消息内容、位置、转账、历史红包、账号管理、图片库、未读和通知入口仍可按现有契约操作；旧存档、旧图片、自定义表情可读。
- 亮色、暗色、窄屏手机、桌面手机窗口的内容不溢出；无首次免责声明。
- 构建产物不含已撤销的内置表情图片。

## 测试所有权与验证范围

- 当前 Agent：检查玩家可见文案和组件路径；定向静态检查、ESLint/Prettier、Webpack 构建；若本地可用，按真实手机视口预览关键页面。
- SillyTavern 宿主：浮层、通知点击、触屏、存档变量时序和视觉最终验收；当前仓库无自动连接的宿主环境。
- 视觉重构不更改 Store 业务逻辑；原有消息与款项验证证据继续有效，若实施中触及逻辑再补相应回归。

## 文档更新项

- 更新 `技术选型与总体架构` 与 `API/微信正文增量与手机交互` 中已失效的四标签、截图参考和玩家可见名称描述。
- 更新 AI2AI 索引及迭代状态。历史任务保留当时事实。

## 旧机制取缔项

- 退出微信截图导向的玩家可见名称、图标、四标签布局和现实产品服务占位入口。
- 旧 CSS 若失去独立职责，收敛或删除；不让新视觉仅作为旧主题上的覆盖补丁。
