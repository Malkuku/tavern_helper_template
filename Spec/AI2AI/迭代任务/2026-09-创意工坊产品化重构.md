# 创意工坊产品化重构

## 状态

自动化验收完成待宿主验收

## 目标与范围

- 将现有工程验收型创意工坊重构为普通创作者可长期、日常使用的桌面创作工作台。
- 完全保留现有资产数据结构、字段名、字段类型、层级、引用语义、世界书存储格式和资产包契约；本任务不重设计、不扩展、不版本化调整运行时数据模型。
- 为开场白及十二类资源逐类建立固定、语义化的可视化编辑器，使用户只操作领域概念，不接触 JSON、对象、数组、注册表、UUID 或组装逻辑。
- 整体重构用户工作区与开发者工作区的信息架构、视觉层级、状态反馈、弹窗和响应式交互，不在现有工程稿上仅做颜色、圆角或间距修补。
- 完善草稿安全、真实差异审阅、引用导航、发布检查和资产包安装预览，使创作、检查、保存与分发形成闭环。
- 保持创意工坊的既有责任边界：持久化目标仍为当前角色主世界书；开局、创建聊天与运行剧本仍属于尘史模块。

## 关键设计决定

### 数据与编辑边界

- 现有数据结构是本轮不可变边界。可视化仅改变输入和呈现方式，保存结果必须与现有结构一一对应并可被当前运行时直接消费。
- 不支持自定义字段、任意嵌套结构或数据类型选择器。界面不允许创建运行时无法可靠消费的数据。
- 实施前逐类核对现有配置样本、Schema、组装器和运行时消费代码，产出“字段路径—业务名称—控件—默认值—校验—列表摘要—引用关系”映射表；映射未完成前不启动正式编辑器实现。
- 每类资产使用独立领域编辑器或有明确领域职责的共享字段组件。通用递归数据编辑器不得继续作为正式创作入口。
- UUID 只作为内部引用键。正常浏览、选择、冲突处理、引用错误和删除影响优先展示资产名称、分类与上下文；仅在高级诊断详情中允许查看 UUID。

### 页面角色与信息架构

- 开发者工作区采用稳定的工作台结构：资产分类导航、可搜索和筛选的资产目录、领域编辑区，以及与当前内容相关的状态和操作区。
- 页面首要任务是定位资产、编辑内容并安全保存。项目级操作与当前资产操作分层，保存、未保存状态和阻断问题必须持续可见。
- 用户工作区围绕资产包管理和运行时角色加入组织，不展示开发者术语；资产包安装前必须提供内容、变更和冲突预览。
- 资产目录以用户可识别信息为主，至少包含名称、分类及必要状态摘要；不以 UUID 作为主要标题。
- 窄屏不能只压缩桌面三栏。允许导航和目录切换为抽屉或分步布局，但当前资产、未保存状态和核心动作不能丢失。

### 视觉与组件系统

- 建立创意工坊局部设计令牌和统一基础组件，覆盖颜色、字体层级、间距、边框、按钮、输入控件、选择器、标签、状态徽章、空状态、加载状态、错误状态、工具提示、模态框和抽屉。
- 延续尘史暗色创作工具气质，但以长时间阅读与编辑的可读性、对比度和操作辨识度为优先；不能只靠金色表达主次。
- 通过空间、排版和结构表达层级。主操作、次操作、危险操作和只读状态必须有稳定且一致的视觉语义。
- 看起来可点击的元素必须承担真实动作；不添加没有现有业务或数据契约来源的装饰性模块与虚假功能。
- 原生 `alert`、`confirm`、`prompt` 不作为正式产品交互，统一替换为可说明影响、可取消且焦点行为正确的应用内对话框。

### 草稿、审阅与安全

- 清晰显示未保存状态；重新读取、放弃草稿、收起或离开可能丢失编辑内容时必须阻止无提示丢失。
- 保存审阅必须展示真实变更：新增、修改、删除的资产，以及字段级变更摘要；不能只显示“存在差异”。
- 引用问题、删除影响和资产包冲突必须展示可识别的来源、目标和动作后果，并支持跳转或定位到相关资产。
- 发布检查以创作者可行动的语言区分阻断问题、警告和通过项；内部校验错误需要转换为字段级提示或可定位问题。
- 本任务不承诺持久化版本历史。若实现撤销、临时恢复或本地草稿，只能作为编辑安全能力，不改变世界书的权威持久化边界。

### 原型与实施门禁

- 正式实现前先产出覆盖主要状态的高保真页面方案或可交互原型：正常编辑、空分类、新建资产、未保存、校验失败、删除影响、导入预览、导入冲突、加载与失败、窄屏布局。
- 原型字段和动作必须能映射到现有契约；不得用静态假功能填满页面。
- 原型确认后按领域职责拆分 Vue 组件和状态，不把整份原型直接塞入单个组件，也不把 mock 数据带入正式实现。

## Agent 分工

- 主 Agent：任务定界、数据契约保护、原型审阅、实施协调、交付物审阅、Spec 与状态收口。
- 产品与界面设计 Agent：逐类字段映射、用户流程、信息架构、设计系统和多状态原型；不修改数据契约。
- 前端实现 Agent：按确认原型落地工作台、领域编辑器、弹窗、草稿状态、差异审阅与响应式行为，并完成实现自测。
- 独立验收 Agent：从本任务验收标准独立推导用例，验证数据无损、用户主路径、异常路径、视觉状态和宿主环境表现；不以实现 Agent 的测试代替正式验收。

## 验收标准

### 数据无损与结构封装

- 开场白与十二类资源均有符合其现有固定结构的领域编辑入口，不以通用递归对象编辑器作为正式入口。
- 用户在正常主路径中不需要理解或输入 JSON、对象/数组类型、注册表、UUID 或内部组装术语。
- 每类资产可完成现有结构支持的创建、查看、修改、复制和删除；编辑保存后字段名、类型、层级和引用语义不变。
- 对真实现有资产执行“读取—不修改保存”和“修改单字段—保存—重读”时不发生未知字段丢失、类型漂移、数组重排或引用破坏。
- 界面不能创建当前运行时无法消费的自定义字段或任意结构。

### 开发者工作区

- 分类导航、资产目录和编辑区层级清晰；用户可通过名称和业务描述定位资产，UUID 不作为主要识别信息。
- 新建资产提供与现有结构一致的完整默认表单，不出现空对象或要求用户自行添加内部字段。
- 当前资产的未保存状态持续可见；可能丢失草稿的操作均有明确拦截和后果说明。
- 保存审阅列出新增、修改、删除及字段级差异，并能将校验或引用问题定位到对应资产与字段。
- 删除被引用资产前展示具体影响来源和清理结果；取消不改变草稿，确认后按既有级联语义执行。
- 剧本发布检查明确展示是否可用、阻断原因和修复入口；不能只输出 UUID 错误列表。
- 搜索、分类切换、新建、复制、删除、保存和放弃等高频操作在常见桌面宽度下无需横向滚动，核心动作无需滚动到不可预期位置寻找。

### 用户工作区

- 导入前展示资产包基本信息、各分类数量、新增项、相同项、冲突项及引用完整性结果；无冲突时也不得无预览直接写入。
- 冲突决策以资产名称和分类为主，并清楚解释覆盖、跳过、复制并重映射的后果。
- 导出前展示导出范围与内容摘要；全量导出和开发者选择导出的既有能力保持可用。
- 运行时角色列表提供可识别摘要、空状态和成功/覆盖/取消/失败反馈，不暴露内部存储路径。

### 视觉、交互与可访问性

- 页面呈现为统一的正式创作工作台，不再是若干默认按钮、输入框和边框面板的工程拼装。
- 排版、间距、颜色和组件状态在用户与开发者工作区保持一致；主次操作、危险动作、禁用和只读状态可直接辨认。
- 输入控件具有持久标签；错误不只依赖颜色表达；键盘焦点可见；应用内模态框具备正确的焦点进入、关闭和取消行为。
- 空状态、加载、成功、失败、无搜索结果、无可用角色和无资产等状态均有明确说明和下一步动作。
- 在真实 SillyTavern 宿主的目标宽度下无横向溢出、宿主样式污染或关键控件不可读；窄屏可完成核心编辑和保存路径。
- 连续完成“新建剧本—创建或选择依赖资产—修复发布问题—审阅差异—保存—导出”的人工任务时，不需要查看源码、世界书原始 JSON 或外部说明才能理解下一步。

## 测试所有权与验证范围

- 设计验证：使用逐类字段映射表检查原型中的每个可编辑字段、派生展示和动作均有现有数据或业务来源；覆盖桌面、窄屏及全部关键状态。
- 实现自测：为各领域编辑器提供真实结构 fixture，覆盖读写往返、默认值、字段校验、嵌套固定结构、引用选择、未保存拦截、差异计算、删除影响和导入预览。
- 数据回归：继续执行创意工坊现有引用、级联删除、包解析、冲突、复制重映射和原子保存验收；补充所有资产分类的无损往返测试。
- 前端验证：运行创意工坊范围 ESLint、TypeScript 可执行范围检查和开发构建；使用浏览器或宿主进行布局、键盘、焦点、滚动和交互状态验证。
- 独立验收：从用户任务出发覆盖首次进入、空数据、大型资产列表、编辑保存、误操作取消、损坏输入、缺失引用、导入冲突和写入失败，不只复跑实现自测。
- 宿主人工验收：在真实 SillyTavern 中验证全视口挂载、宿主样式隔离、不同宽度、世界书持久化、文件下载上传、MVU 角色写入、收起与卸载。
- 视觉验收证据：保存主要流程及关键状态的截图，逐项对照确认原型；构建成功不能替代交互和视觉验收。

## 旧机制取缔项

- 移除 `StructuredValueEditor` 作为世界、主线、事件、任务、势力、地图、地图节点、季节与节日、种族、角色等资产正式主编辑入口的职责；若仅为诊断保留，必须与普通用户路径隔离并说明用途。
- 移除以 UUID 作为资产列表标题、冲突项主标识和引用错误主要描述的交互。
- 移除浏览器原生 `prompt`、`confirm` 承担新建字段、删除影响和角色覆盖等正式交互的路径。
- 移除“草稿存在差异”这一伪差异预览，由真实资产级和字段级审阅取代。
- 移除重新读取、放弃、收起或离开时可无提示丢失草稿的路径。
- 移除资产包无冲突即跳过预览并直接安装的路径。
- 取代当前依赖默认控件与平面面板拼装的工程稿布局；不保留两套并行的旧、新工作台入口。
