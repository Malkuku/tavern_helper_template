# 次要角色通用恶堕度与角色评级

状态：实现与定向验证完成；待宿主联调。

## 目标与范围

魔法少女次要角色沿用主要角色的 `人设阶段.恶堕度` 结构。主世界书提供唯一的 `<模板>通用恶堕值` JSON 条目；从世界书角色资源加入运行态、唯一开局组装和新人物收录时，为缺少该字段的次要角色补入模板。现有等级与经验不被覆盖。次要角色档案显示当前等级与对应描述。

后续补充：主要角色和次要角色的 `当前评级` 均独立于身份和背景保存，两类描述均保留。次要角色生成结果明确给出评级字段；未知评级为空字符串。旧存档缺字段时继续可读，新的角色资源与运行态角色都带此字段。

## 关键设计

- 模板是通用初值，保存 `当前等级`、`累计经验` 与 0～6 级 `描述`；各角色后续可拥有专属描述。
- 模板解析和补齐集中在同一模块。模板缺失或无效时拒绝新增，不写入缺少恶堕度的半成品角色。
- 工坊的尘史剧本角色使用另一套数据模型，本轮不套用魔法少女模板。
- 旧存档中已有次要角色保持原数据；展示时容忍缺少恶堕度。替换已有角色不重置其恶堕进度。
- 主要与次要角色沿用 `user.当前评级` 的字符串字段命名；次要角色生成时只记录剧情中已明确的评级，不从能力或身份猜测。身份记录角色身份，背景记录经历与关系，不混入评级。现有主要角色世界书资产中明确写出的评级拆出字段，身份保留其余描述。
