# 微信图片库与账号管理

## 状态

实现与定向验证完成；待酒馆宿主角色卡导出、变量持久化及手机交互联调。

## 目标与范围

- 上传的微信头像和表情包图片保存为脚本变量中的共享图片库，微信账号的头像和表情包字段继续保存资源 URL 字符串，由界面解析库内 URL。
- 微信增加账号管理入口，可管理全部账号（包括未发现账号）的昵称、头像、表情包和双向好友关系。图片可被多个账号复用，并可清理未被引用的图片。
- 既有外部 URL、data URL 和表情包备份须继续可读，并迁移到新的权威路径；不改变微信消息中的 `<表情包>名称</表情包>` 协议。

## 关键设计决定

- `magicGirlWeChatImageLibrary` 是脚本变量中的图片内容库，图片以稳定 ID 索引，库内 URL 只保存该 ID；现有普通 URL 和 data URL 仍可作为外部资源读取。
- 账号资料和好友关系由当前楼层 `stat_data.手机.微信.账号` 负责；好友编辑同时更新双方，保持对称。
- 管理页、常规聊天与通讯录读取微信账号表；目标发现状态不限制微信好友与会话展示。
- 账号管理入口要求输入硬编码密码 `987`；离开管理页后重新进入需再次输入。
- 既有 `magicGirlWeChatStickerSnapshot` 中的图片与名称在迁移后写入新图片库与账号引用，旧备份变量不再作为长期写入路径。

## Agent 分工

- 当前 Agent：设计、实现、定向验证、文档收口。

## 验收标准

- 上传图片后的脚本变量包含图片内容，账号字段保存库内引用；头像、表情包、消息卡片可显示。
- 同一图片可供多个账号选择；未被任何账号引用的图片可清理，被引用的图片不能清理。
- 管理任一账号的昵称、头像、表情包与好友后，重开手机仍可读取；好友关系双向一致。
- 未输入正确密码不能进入账号管理页；普通微信页仍按原规则显示。
- 旧 data URL、外部 URL 与旧表情包备份仍可读取并迁移，旧存档不会丢图；图片库缺项时给出可见错误，不静默保存空图。
- 聊天、消息与未发现目标的普通展示规则不回退。
