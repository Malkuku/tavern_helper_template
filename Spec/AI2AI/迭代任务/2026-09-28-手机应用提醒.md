# 手机应用提醒

## 状态

实现与定向验证完成；待宿主触屏、变量时序与视觉联调。

## 目标与范围

微信沿用会话未读红点和顶部消息通知。魔女恶堕计划在任务可领奖时显示桌面与导航红点，并在手机屏幕顶部显示可点开的应用通知。已发现且可观测的主要角色若创伤稳定度当前等级 ≤2，显示黄色应用警告。

## 关键设计决定

- 任务状态直接读取当前楼层 `stat_data`；领奖红点直到领取。免费刷新状态在任务页展示，不作为红点提醒。
- 应用通知复用手机顶部卡片位置，点击直达任务或观测；微信通知优先显示。手动关闭只关闭当前提示，不改变业务状态。
- 顶部卡片仅在手机打开时按聊天展示一次，展示即把当前提醒 key 写入脚本变量。手机重开或脚本重载不重复提示；稳定度等级变化、恢复后再次跌入警告范围，或任务提醒先解除再出现时，重新提示。红点仍直接反映当前状态。
- 稳定度只使用已发现主要角色的当前等级，≤2 触发黄色警告；不解释等级为百分比。点击警告定位到对应角色观测概览。
