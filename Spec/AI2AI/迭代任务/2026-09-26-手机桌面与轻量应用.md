# 手机桌面与轻量应用

状态：实现与本地静态验证完成；宿主触屏和脚本变量读写待联调。

## 目标与范围

手机状态栏和桌面日期读取当前楼层 `stat_data.世界.时间`；桌面支持分页，文件夹内应用通过拖拽移出；提高文件夹与控制中心背景不透明度，桌面底部指示条用于退出手机，应用内同一位置用于返回桌面。

备忘录保存在手机脚本变量 `magicGirlPhoneNotes`。电话提供 DeepSeek、Gemini、GPT 三个模拟联系人，呼叫后提示无法接通。天气读取 `stat_data.世界.天气` 和地点并绘制简易 SVG；日历显示现实设备的月份，无外部 API 依赖。

其余应用采用轻量交互：信息将短信草稿保存在 `magicGirlPhoneMessageDraft`；照片和相机从设备选图并保存在 `magicGirlPhonePhotos`，单图限制 2 MB；地图显示当前世界地点与地图索引；浏览器在新窗口打开输入的网址；音乐播放本地所选音频，关闭应用后释放临时 URL；文件汇总备忘录和照片数量；设置展示当前世界状态并指向控制中心。照片、短信草稿和备忘录均不进入剧情 `stat_data`。

## 关键设计与验收

- 世界时间不随现实时间计时；未设置时明确提示。
- 桌面每页最多 12 个图标，页点可点击，触屏可左右切页；布局仍由 `magicGirlPhoneLayout` 保存。
- 文件夹内图标可拖到遮罩空白处移出；移出后布局写回脚本变量。
- 备忘录新建、编辑与删除写入脚本变量；关闭手机重开仍可读取。
- 信息草稿与照片可保存和重新读取；相机走设备拍照或选图入口。浏览器只接受 HTTP(S) 网址。
- 桌面底部指示条退出手机；应用内底部指示条返回桌面。
