# 剧本工作台视觉与自由主线整改

## 状态

自动化验收完成待宿主验收

## 目标与范围

- 修复角色技能名过长时撑破技能卡的问题。
- 重构剧本工作台的分区导航、主题选择和整体信息层级。
- 剧本资源侧栏复用所选主题的共享 SVG，并由 SVG 状态徽标直接表达当前可用性；提升共享剧本 SVG 的细节质量。
- 主线、任务和事件在工坊中直接复用运行时完成品视觉，并在原位进入编辑状态。
- 将主线从固定字段表单纠正为保留任意 JSON 结构的自由编排器，提供可组合、可绑定、可独立选择视觉的通用组件。

## 关键设计决定

- 遵守《视觉复用与参考保真规则》：剧本主题继续由 `ScenarioVisualCard`
  和共享主题注册表统一提供，叙事卡片抽取为运行时与工坊共同消费的组件。
- 主线业务数据保持 `Record<string, unknown>`，不再假定每条主线都有 `描述/警惕度/详细/已交融的魂质`。
- `主线.meta`
  是持久化的主线视图契约，保存各主线条目的组件树、数据路径绑定、顺序、嵌套和独立视觉变体；EJS/MVU 业务主线读取应忽略该键，玩家主线页面直接消费它。
- 通用组件首批提供标题、正文、指标、列表、标签、分隔线和容器。标题、正文、指标、列表和标签绑定当前主线条目内的任意 JSON 路径；容器承载子组件。
- 旧数据缺少 `meta` 时，工坊基于当前条目的真实字段补齐默认编排；运行时不写数据，只使用兼容展示。
- 任务、事件仍保持现有固定业务字段，但默认展示运行时完成品卡，选中后原位编辑。
- 本轮不引入拖拽画布、连线图、绝对定位或新的持久化格式。

## Agent 分工

## 验收标准

- 无空格的超长技能名在桌面和移动端均不横向溢出；展示态先缩小到正文可读字号，仍放不下时才单行省略，并在悬浮时自动横向巡航展示全名，等级、性相和编辑按钮保持可用。
- 左侧剧本资源条目使用所选主题的共享 SVG，并具有清晰的标题、主题与状态层级；可用性由 SVG 状态徽标呈现，不再显示“可玩 / 编辑中”状态文字。
- 九种剧本主题图标在相同尺寸下具有与破镜主题相当的多层轮廓和内部细节，并继续由所有剧本入口共享。
- 剧本页面在桌面端形成稳定侧栏导航与内容工作区，移动端退化为横向可滚动分区导航。
- 主线可新增、重命名、复制、排序、删除，业务 JSON 读取—编辑—保存不丢失未知字段。
- 主线编排具有组件库、画布和当前组件设置；组件可新增、选择、复制、排序、删除和嵌套，每个组件独立选择视觉变体并绑定数据路径。
- 玩家主线页面按 `主线.meta` 渲染实际编排结果；组件选择不是只改变整个列表排版的预览按钮。
- 主线、任务、事件默认展示正式视觉；编辑操作不另开 JSON 编辑器、侧栏或弹窗。
- 原有剧本组装、角色选择、地图选择与可玩性判断保持有效。
