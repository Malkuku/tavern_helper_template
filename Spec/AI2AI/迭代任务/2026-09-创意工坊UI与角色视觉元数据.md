# 创意工坊 UI 与角色视觉元数据

## 状态

自动化验收完成待宿主验收

## 目标与范围

- 重构创意工坊用户工作区与开发者工作区的信息架构和视觉层级，并沿用尘史使徒的暗色、金色、叙事化视觉语言。
- 为角色资产增加头像引用与对话颜色元数据，并让创意工坊、运行态角色、尘史角色页和特殊对话框消费同一份数据。
- 将尘史使徒的嵌套地图地点选择能力用于剧本初始 `地图索引`，不恢复地图资产选择。

## 关键设计决定

- 角色资产新增同级字段 `meta: { avatar: string; color: string }`；组装或运行时加入角色时复制到运行角色对象的 `meta` 字段。
- `avatar` 接受普通 URL 或 SillyTavern 可读取的本地资源路径；本轮只保存引用，加载失败显示默认头像，不上传或打包图片二进制。
- `color` 只影响主要角色特殊对话文本框；角色页和普通卡片不以该颜色整体染色。
- 用户工作区移除派生标签。提供默认勾选的“隐藏已在运行中的角色”；取消后显示已有角色，动作标为“替换”，三类角色均展示差异并确认后完整替换。
- 资产包使用明确的“导入资产包”主按钮和相邻导出动作，不再占据独立大栏。
- 初始地点选择器消费当前唯一完整地图，结果写入剧本私有世界资源的 `data.地图索引`。

## Agent 分工

- 主 Agent：契约、实现、实现自测、视觉审阅材料和文档收口。

## 验收标准

- 用户工作区角色卡展示头像、名称、类型和可识别摘要，并有明确“加入/替换”按钮；无派生标签筛选和内部术语说明。
- 默认隐藏运行态已有的同 `type + key`；`user` 同样隐藏。取消勾选后可见并经差异确认完整替换。
- 角色编辑器可编辑头像引用与颜色；保存、重读、复制、差异和 v2 包导入导出均保留 `meta`。
- 组装与运行时加入后的角色对象包含 `meta`；失败回滚语义不变。
- 尘史角色列表和详情展示头像并在失败时回退；主要角色特殊对话框读取运行角色 `meta.color` 和 `meta.avatar`，不再依赖名称硬编码表。
- 剧本初始地点可通过嵌套地图选择器选择，且不出现地图资产选择入口。
- 开发者工作区在常见宽度下保持资产导航、编辑内容、发布问题和保存动作可见，窄屏不直接丢弃状态信息。
- 导入资产包按钮明确可见；相关提示只描述用户动作、结果与风险。
