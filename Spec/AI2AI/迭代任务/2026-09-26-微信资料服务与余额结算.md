# 微信个人资料、服务与余额结算

- 状态：实现完成；宿主 MVU 交互待联调
- 目标：个人信息提供简化编辑页；服务可进入钱包；钱包余额读取 `stat_data.角色.user.金钱`；微信转账与收款更新同一变量。
- 范围：微信“我”入口、个人信息、服务与钱包页面，微信消息确认与款项操作的变量写入，相关契约。
- 决定：资料昵称和头像写入 `手机.微信.账号.user`；钱包余额只读角色金钱。发送转账在消息经正文确认入库时扣款；领取 NPC 转账或红包时入账；user 转账被退回时退款。结算与消息变更原子写入，金额按分精确计算，余额不足时报错。
- 分工：当前 Agent 负责实现与定向验证；无独立 Agent。
- 验收：资料保存后重新打开仍在；服务和钱包可进入；钱包显示真实余额；收款与转款按金额增减，重复日志或重复领取不重复结算；非法金额和余额不足无部分写入。
- 验证：本地构建、定向逻辑检查；宿主 MVU 交互仍需联调。
- 文档：更新微信交互 API 中旧的“不结算金额”描述。
- 旧机制：移除“款项操作只更改卡片状态”的旧规则。
