# 手机脚本变量备份

状态：实现与本地验证完成；待 SillyTavern 宿主联调。

## 目标与范围

手机“设置”提供当前手机脚本变量的备份、JSON 导出与恢复。备份写入酒馆助手全局变量，独立于被备份的脚本变量；导出下载 JSON 文件。只处理当前脚本的变量表，不包含最新楼层的
`stat_data`、聊天变量或其他脚本。

## 关键设计

- 每个脚本 ID 在全局变量表中使用独立备份键，保存一次完整快照；再次保存覆盖该脚本的旧快照。
- JSON 包含格式、版本、来源脚本 ID、备份时间和完整变量对象。本地备份与导出使用同一格式。
- 可从本地备份或符合格式的 JSON 文件恢复。恢复完全替换当前脚本变量；执行前展示来源并要求用户确认。恢复后提示重开手机以刷新界面缓存。
- 读取、序列化、写入、解析失败都在界面明确显示，不误报成功。全局变量更新只修改该备份键。

## 分工与验收

单 Agent 实现与验证。验收：脚本变量快照与导出内容一致；本地备份保存后可读；恢复可完整覆盖当前脚本变量；无效文件不能覆盖；下载、恢复及宿主变量持久化需在 SillyTavern 联调。

## 验证范围

备份数据结构和错误路径的定向验证，目标源码静态检查与手机入口构建；宿主手工验证文件下载和酒馆全局变量读写。
