# 物品技能图标与仓库管理

状态：实现与定向验证完成；宿主 MVU 与触屏视觉待联调。

## 目标与范围

- 为手机变量中的物品、技能增加完整 SVG 图标字段，并在手机界面展示。
- 将随身物品和仓库收进同一个手机仓库管理界面，支持查看两处库存、按数量存入和取出。
- 参考 `src/尘史使徒/UI/view/仓库.vue` 的双库存、选择数量与提交变更结构，沿用手机既有视觉。遵守《视觉复用与参考保真规则》：此处参考的是结构与处理逻辑，不移植尘史视觉。

## 关键设计决定

- `图标` 是物品和技能对象的 SVG 字符串。旧楼层缺失时显示现有默认图形，不改写旧存档；新开局校验接受字段并验证完整安全 SVG。
- 桌面保留两个既有入口以免破坏布局配置，二者进入同一管理页，入口分别预选随身物品和仓库。
- 转移以物品名称为键，数量必须为正整数且不超过当前来源数量。目标已有同名物品时仅累加数量，来源物品在零数量时删除。
- 界面变更先暂存，确认时在 Store 的串行写入队列中重新读取最新楼层并验证源库存，原子写回两侧；刷新或切换聊天后取消未提交草稿。失败保留草稿并显示原因。
- 物品使用、批量删除不属于本轮魔法少女仓库需求；参考模块的对应操作不移入手机。

## Agent 分工

## 验收标准

- 物品与技能 SVG 字段可通过新开局契约验证，在对应卡片显示；非法 SVG 被拒绝，缺失图标的旧数据安全回退。
- 两入口打开同一仓库管理页并预选对应库存；同屏可切换随身和仓库、查看详情和数量。
- 部分或全部数量可以存入和取出；同名物品合并数量、零数量条目删除；确认后最新 MVU 两侧一致。
- 库存变化或聊天切换时不得把过期草稿写入新楼层；保存失败可见且草稿仍可重试。
