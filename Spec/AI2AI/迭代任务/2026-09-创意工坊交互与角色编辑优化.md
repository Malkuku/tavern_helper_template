# 创意工坊交互与角色编辑优化

## 状态

自动化验收完成待宿主验收

## 目标与范围

- 修复创意工坊角色目录在长名称和大量角色下的挤压、重复与难以辨认问题。
- 将开发者工作区调整为剧本优先，并以“角色身份 → 版本”的二级折叠结构呈现同名角色。
- 将工坊入口改为默认悬浮球，并支持拖拽；展开窗口保持全屏工作区。
- 完善角色头像、主题颜色、默认头像样式和角色领域字段的专用编辑体验。

## 关键设计决定

- 角色目录一级项按 `type + key` 聚合为角色身份，二级抽屉列出具体版本；抽屉与编辑区版本说明默认收起。
- 版本用作者、引用剧本、摘要和字段差异区分，不再向用户使用“同 type + key 变体”作为标题。
- 角色视觉元数据扩展为 `meta.avatarStyle`；空头像时根据角色 key 做稳定 hash，并允许作者选择自动或指定默认头像样式。
- 头像文件和屏幕截图以 data URL 写入 `meta.avatar`，与 URL、SillyTavern 本地资源路径使用同一预览和保存链路。
- 角色类型、品质、性相、关系对象、地图位置与剧本引用等已知枚举或引用继续使用专用选择器，不退回通用 JSON 编辑。

## Agent 分工

- 主 Agent：契约、界面实现、实现自测、验证和文档收口。

## 验收标准

- 工坊加载后默认只显示可拖拽悬浮球；点击展开，拖拽不误触打开。
- 开发者工作区默认打开剧本域，剧本入口排在角色之前。
- 长名称和大量角色不再互相覆盖；一级角色身份不重复，版本抽屉默认收起并可定位具体版本。
- 角色版本能用作者、引用剧本、摘要和差异字段区分，版本关系说明不出现内部实现术语。
- 头像可输入资源地址、选取本地图片、截取屏幕并预览；主题颜色文案统一。
- 空头像按角色 key 稳定显示多种默认样式，作者可指定样式，保存与运行态传递不丢失。
- 角色长表单采用可折叠领域面板，明确枚举和引用字段提供专用选择器或候选。
