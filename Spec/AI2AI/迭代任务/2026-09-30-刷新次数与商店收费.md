# 刷新次数与商店收费

## 目标与范围

- 组织任务由每天一次免费刷新改为每世界周五次，任务页显示本周剩余次数。
- 道具商店取消前三次免费，普通刷新每次 5 积分。
- 技能商店取消首次免费，普通刷新按 5、10、15、20、20……积分计价。
- 定向刷新仍在普通报价上加 50 积分；生成失败或取消不计次、不扣费。

## 设计与验收

- 沿用现有任务刷新字段，`任务下次刷新时间` 改为下周一 00:00；`任务主动刷新次数` 记录本周成功次数。旧的每日刷新记录在所属周内计为一次。
- 周一重置任务可用次数；成功五次后拒绝第六次；显示剩余 0/5。失败不消耗次数。
- 商店首次普通刷新报价非零，后续报价和周重置符合上述规则。
- 当前 Agent 负责实现及定向行为验证；更新三个 API 契约与索引。本地验证覆盖定向脚本、静态检查和构建；宿主生成时序留待联调。

## 旧机制取缔项

- 移除任务每日一次的判断与提示、道具前三次免费和技能首次免费的报价规则及过时的稳定文档描述。
