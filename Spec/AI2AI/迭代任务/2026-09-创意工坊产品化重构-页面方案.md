# 创意工坊产品化重构：页面与状态方案

## 设计目标

工作台首屏只回答三件事：我在编辑什么、它是否安全可保存、下一个有效动作是什么。视觉延续暗色创作工具气质，但主次关系由布局、标题和间距承担，金色仅用于当前位置和主动作。

## 桌面信息架构

```text
全局顶栏：创意工坊 | 用户工作区 / 开发者工作区 | 世界书连接状态 | 收起
开发者工作区
├─ 分类导航 184px：开场白 + 12 类资产、数量、问题徽标
├─ 资产目录 288px：分类标题、搜索、筛选、新建、名称/摘要/状态
├─ 领域编辑区 minmax(520px, 1fr)：资产标题、表单分组、字段错误
└─ 状态操作栏 280px：草稿状态、发布检查、引用摘要、当前资产动作
底部粘滞保存栏：未保存数量 | 放弃草稿 | 审阅并保存
```

目录项不展示 UUID。无 `key` 分类的标题须从已确认的真实领域字段派生；在样本未补齐前，可暂用 `desc` 但必须标记“未命名资产”，不回退到 UUID。

## 核心交互

### 定位与编辑

- 分类切换保留各分类搜索词和滚动位置；有草稿时可切换，不丢失当前修改。
- 新建直接生成完整固定表单和内部 UUID，焦点进入第一个必填业务字段。
- 复制产生新 UUID，保留内容，并将可识别名称标记为副本；不自动改动引用。
- 引用选择器以名称、分类、摘要和可用性展示；缺失引用保留原 UUID 值，显示“已缺失的目标”并提供重新选择。
- 引用摘要可跳转到来源或目标资产；跳转前保留草稿，返回后恢复原位置。

### 草稿安全与保存

- 任一字段改动后，顶栏和底部栏持续显示“N 项未保存”。
- “重新读取”、“放弃草稿”、“收起”、关闭 iframe 或页面离开均进入丢失拦截对话框，说明受影响资产数量；默认焦点在“继续编辑”。
- “审阅并保存”打开真实差异抽屉：按新增、修改、删除分组，每个资产展示字段路径、业务名称、旧值和新值摘要。敏感长文本使用折叠前后片段，不用“存在差异”代替。
- 校验错误阻止保存并可定位到字段；引用不完整允许保存，但清晰预告相关开场白将被标记为不可用。
- 保存期间锁定写操作，保留阅读上下文；失败后草稿和差异不消失，主动作变为“重试保存”。

### 删除影响

无引用时使用普通确认对话框。有引用时显示每个来源的名称、分类、字段和清理后结果；主动作为“删除并清理 N 处引用”，危险色且不是默认焦点。点击来源可先跳转检查，取消不改变草稿。

## 用户工作区

首屏为两个真实任务入口：“管理资产包”和“加入运行角色”。

- 导入始终先进入预览流程：文件解析 → 基本信息与分类数量 → 新增/相同/冲突/缺失引用摘要 → 逐项冲突决策 → 最终变更摘要 → 安装。无冲突也停在预览确认页。
- 冲突项以“分类 · 名称”为标题，可展开看字段差异。覆盖、跳过、复制并重映射均配后果说明；可对全部同类冲突批量决策，但不默认覆盖。
- 导出前打开范围预览：全量导出列出各类数量；开发者选择导出列出选中资产及缺失引用。确认后调用现有下载能力。
- 角色列表支持名称搜索和主要/次要角色筛选，展示名称、类型和来自 `desc` 或真实字段的摘要。目标已存在时用应用内对话框说明将整体覆盖，取消不写入。

## 窄屏方案

在 700px 以下不压缩为三列，改为分步工作流：

```text
顶栏：返回/菜单 | 当前资产名 | 未保存徽标 | 审阅保存
主视图：资产目录 或 编辑表单（一次只显示一个）
左抽屉：分类导航
右/底抽屉：发布检查、引用与当前资产操作
底部粘滞栏：目录/编辑切换 + 保存
```

抽屉打开时焦点进入标题或第一操作，`Escape` 关闭并将焦点返回触发器。当前资产名、未保存状态和审阅保存不随抽屉隐藏。

## 关键状态

| 状态 | 呈现 | 有效动作 |
| --- | --- | --- |
| 首次加载 | 保留布局骨架，标记正在读取主世界书 | 收起 |
| 加载失败 | 可读错误、不暴露原始堆栈，说明草稿未创建 | 重试、复制诊断信息、收起 |
| 空分类 | 分类名、用途和“还没有…” | 新建该类资产 |
| 无搜索结果 | 显示搜索词和当前筛选 | 清除搜索/筛选 |
| 新建 | 完整固定表单，必填项空态不等于立即报错 | 编辑、删除草稿资产 |
| 未保存 | 全局徽标+底栏，目录项小点 | 审阅并保存、放弃 |
| 校验失败 | 字段旁文本错误+问题总览，不只用颜色 | 跳转到字段 |
| 删除影响 | 来源列表、清理后果、危险主动作 | 检查来源、取消、删除并清理 |
| 导入预览 | 包信息、分类数量、新增/相同/冲突、引用完整性 | 取消、下一步/安装 |
| 导入冲突 | 以名称和分类展示的冲突表与真实差异 | 覆盖、跳过、复制并重映射 |
| 保存/安装成功 | 持久状态更新 + `role=status` 通知 | 继续工作 |
| 保存/安装失败 | 明确未部分写入，保留当前上下文 | 重试、取消 |

## 设计系统与可访问性

- 建议局部令牌：背景 `#0d0f10/#15181a/#1d2123`，主文字 `#eee7d8`，次文字 `#b8b09f`，金色强调 `#cbb477`，成功 `#72b58a`，警告 `#d8a95d`，危险 `#d47569`；所有文字/背景组合须达 WCAG AA。
- 8px 间距系统，表单标签始终可见；不用 placeholder 代替标签。焦点环与 hover 状态分离，所有图标按钮有可读名称。
- 状态使用图标+文字+颜色三重表达。错误摘要聚合后不从 DOM 移除字段错误。
- 对话框使用焦点陷阱，打开后聚焦标题或安全动作，关闭后返回触发器；危险操作不作默认回车目标。
- 长列表保持键盘可达，搜索结果数量使用非打断式 live region；保存失败使用 `role=alert`。

## 动作能力核对

页面中所有操作均映射到已有能力：资产 CRUD 与内存草稿、引用检查和级联清理、原子保存、包创建/解析/冲突/合并/下载、运行时角色加入。“真实差异”、“导入/导出预览”和草稿离开拦截是需在现有能力上增加的界面状态与计算，不增加持久化契约。

## 设计门禁结论

- 信息架构、桌面/窄屏、草稿安全、引用导航、真实差异、导入/导出预览、关键状态和可访问性方案已完成。
- 开场白、开场文本、地图拓扑和其他资产外层可直接进入原型/实现拆分。
- 已根据 Beta 十三类真实配置与运行时类型补齐 `data.*` 映射，固定领域编辑器设计门禁通过。Beta `任务` 注册表为空，实现依 `TaskData` 并需专门 fixture 验证。
