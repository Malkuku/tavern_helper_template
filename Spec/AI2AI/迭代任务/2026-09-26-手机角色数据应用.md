# 手机角色数据应用

## 状态

已完成；待宿主视觉与 MVU 联调

## 目标与范围

在现有手机桌面新增主要角色、次要角色、我的档案、技能、随身物品和仓库六个 SVG 应用入口，并从魔法少女 Store 的当前消息楼层 `stat_data` 只读展示对应信息。保留现有手机壳子和微信入口。

## 关键设计决定

- 主要角色与次要角色都按变量中的实际键读取；主要角色采用角色选择与分区档案，次要角色采用列表与详情。
- user 基本信息只展示身份、背景、外貌、性格、评级和货币；技能、随身物品与仓库各有独立应用页。
- 角色搜索词与地图检索词属于运行规则元数据，不作为玩家档案正文。
- 页面只读 Store，不复制数据或写入 MVU；变量缺失时展示空态，不使用演示数据填充。
- 新应用图标用统一线条风格的内联 SVG；现有桌面和微信视觉保留。

## Agent 分工

- 当前 Agent：设计、实现、定向验证和文档收口。不设独立验收角色。

## 验收标准

- 六个桌面图标能分别打开对应页面并返回桌面。
- 动态主要角色与次要角色能切换查看，字段按各自结构展示。
- user 基本信息、技能、随身物品、仓库互不混入；空数据可观察。
- MVU 刷新后页面使用 Store 的新值，不依赖静态样例。
- 手机尺寸可纵向滚动，现有微信和控制中心可用。

## 测试所有权与验证范围
