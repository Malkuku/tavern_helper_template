# 微信数据界面与正文增量

状态：已完成；待宿主事件时序与视觉联调。

## 目标与范围

以 `stat_data.手机.微信` 替代手机微信演示数据，提供实际会话、通讯录、好友请求、个人资料、消息内容与发送流程。处理正文中的 `<WeChatLog>` 增量，涵盖主动聊天和后台聊天。

## 关键设计

- Store 负责读取与写入 MVU；纯数据模块负责会话 key、消息摘要、正文日志校验与增量应用。UI 不解析正文或直接拼写变量路径。
- 用户确认发送时写 `准备发送`，成功后发 `Chat_On_WeChat`；消息由正文日志回写，发送时不预先加入会话。
- 正文检测位于手机 Store 的消息事件入口，按当前聊天的消息楼层和内容识别日志。重复事件不重复写入；异常日志不部分入库，也不清除待发送。
- 好友申请与处理使用当前变量里的请求结构；正文好友事件按规则应用。仅提供类型支持的内容，特殊内容以明确的卡片/摘要展示。
- 会话列表从 `会话` 派生；通讯录从 user 好友派生。私聊 key 固定 `私聊:user&账号ID`，新私聊可以在首次发送时由主动规则创建。

## 分工与验证

- 单 Agent 完成协议解析、Store、Vue 页面、样式与文档。
- 验收：变量驱动的真实列表与详情；文字发送只写缓冲并触发事件；主动/后台日志入库，重复日志不重放；好友申请操作和嵌套内容展示；聊天切换不串数据。
- 定向测试正文协议成功、失败、重复与好友事件已通过；Webpack 开发构建、相关 ESLint/Prettier 已通过；宿主事件时序与视觉留待实测。
