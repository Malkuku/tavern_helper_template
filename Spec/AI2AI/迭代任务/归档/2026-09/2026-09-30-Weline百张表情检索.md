# Weline 百张表情检索

## 状态

实现与本地静态验证完成；待 SillyTavern 宿主触屏与百张真实图片视觉联调。

## 目标与范围

在约 100 张表情与图片的规模下，聊天发送、账号选用、图片库找图无需逐项翻找。保留现有图片、表情和账号存储契约。

## 设计决定

- 聊天表情按名称即时筛选，显示结果数和无匹配状态。
- 账号表情页将当前账号已选表情与共享库切换展示；共享库与已选表情按名称筛选，当前账号的选用状态仍可见。
- 图片库可按图片 ID 或引用该图片的具名表情名称筛选；搜索跨文件夹，文件夹浏览在清空搜索后恢复。无具名表情的旧图片仍靠缩略图、ID 和文件夹识别。
- 本轮不变更脚本变量、表情发送协议和图片分类结构。

## 分工与验收

- 当前 Agent：实现、定向检查、文档收口。无独立测试 Agent。
- 以 100 条表情数据检查搜索结果与空态；验证切换账号、清除搜索、选用和发送入口仍可用；运行目标文件格式与构建检查。

## 文档更新

- 更新 Weline 交互契约与索引，记录图片搜索的信息边界。

## 完成记录

聊天表情面板增加名称搜索，搜索框在表情网格滚动时保持可见；账号管理将共享库和当前账号已选表情分开浏览，并提供名称搜索；图片库跨文件夹搜索图片 ID 或关联的具名表情名称，缩略图显示关联名称。搜索仅影响浏览，不修改脚本变量或图片引用。

目标 Vue 文件 ESLint、Prettier 与 Webpack 开发构建通过，`git diff --check` 通过。当前环境未连接 SillyTavern 宿主，百张真实图片的触屏滚动、渲染负载和搜索体验仍待宿主联调。图片库没有保存原始文件名；未入具名表情库的图片不能按文件名搜索。
