# 魔法少女唯一开局组装

状态：已完成；待宿主 MVU 联调。

## 目标与范围

以唯一开局和完整角色 JSON 组装新聊天的 `stat_data`；角色列表继续从运行变量向叙事提供人设。移除 `StatData` 完整初值、逐字段 `<人设配置>` 标签和版本覆盖路径。不处理旧存档。

## 关键设计

- 世界书保存 `唯一开局`、`角色资源`、`地图资源`。唯一开局包含固定数据与恰有一项的 UUID 开局注册表，按 UUID 引用角色与地图，初始仓库属于该开局内容；固定数据只保存各开局共享的系统与空容器。
- 组装前校验开局和资产，组装后按与 `types.ts` 对齐的运行时 schema 校验完整结果。
- 仅当当前楼层 `stat_data` 恰好为 `{ "作者": 987 }` 时，手机按引用组装并写入当前楼层；后续打开只使用已有运行状态，不覆盖角色字段。
- 缺失、重复或非法资源报错，禁止写入半成品变量。

## 分工与验收

- 单 Agent 完成卡资源迁移、初始化器、定向测试与 Spec。
- 验收真实角色字段完整、初始化幂等、游玩值不被覆盖、非法配置不写入、构建通过。
