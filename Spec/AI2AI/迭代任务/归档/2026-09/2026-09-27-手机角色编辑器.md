# 手机角色编辑器

## 状态

实现与定向验证完成；宿主世界书写入、MVU 和视觉待联调。

## 目标与范围

在小手机桌面增加角色编辑器。读取和保存当前角色主世界书 `<配置>角色资源`
中的角色资产；支持编辑、新建角色资产，并将选中的资产加入或完整替换当前聊天的运行态角色。角色头像、主题色和默认头像样式沿用工坊
`meta`；主要角色与 user 的默认微信账号头像由资源头像生成，运行态加入/替换时同步对应账号头像。界面使用现有手机视觉语言。

## 关键设计决定

- 主世界书角色资源是编辑的权威数据源；角色编辑只改世界书，不自动覆盖当前聊天角色。加入/替换才修改当前楼层 `stat_data`。
- 用固定字段表单编辑常用角色内容与头像主题；复杂角色结构保留原值，完整结构可通过 JSON 编辑区修改和新建，保存前严格按手机角色数据 Schema 校验。
- 保存前在手机内确认资产变化；替换运行态前展示字段差异并确认。放弃未保存草稿时拦截。
- 微信账号头像以 `meta.avatar`
  为源；没有图片时用与角色头像相同的稳定默认头像。只在默认账号创建或角色明确加入/替换时同步头像，保留用户在微信里手工修改的昵称和其他账号资料。
- 新建角色资产生成 UUID；同 `type + key` 可保留不同版本，运行态同身份只保留一份。`user` 资产的 key 固定为 `user`。

## Agent 分工

- 当前 Agent：设计、实现、定向验证和文档收口；不设独立验收角色。

## 验收标准

- 手机桌面入口能读取、编辑并保存 `<配置>角色资源`；错误或非法草稿不改世界书。
- 角色资产可新建、编辑头像主题和角色数据；列表能区分身份和版本。
- 加入/替换当前角色经过明确确认，成功后当前数据刷新，失败不留下部分角色写入。
- 首次开局默认微信账号使用角色头像；运行态加入/替换会生成或同步相应微信账号，头像与角色展示一致。
- 既有 JSON 增加 `meta`，开局组装接受并传递它。
