# 2026-09 创意工坊 AI 地图生成

## 状态

自动化验收完成待宿主验收

## 目标与范围

- 在地图目录与当前地图操作区增加外部 AI 新建、修改入口，复用角色的“下载提示词—外部对话—粘贴 JSON—进入草稿”流程。
- 地图提示词以零上下文方式解释 `MapEntry`、递归节点、检索词、文案、坐标区间和安全 SVG 的字段规则。
- AI 在生成最终 JSON 前可先用自包含 HTML 展示地图方案，供作者审阅空间层级、节点分布和图标风格；HTML 不进入工坊执行或保存。
- 最终只导入完整 `MapEntry` JSON；新建产生地图草稿，修改完整覆盖当前地图草稿并保留 UUID。

## 关键设计决定

- 不恢复宿主模型直调；沿用已经验证的外部 AI 协作路径。
- HTML 是外部对话中的设计审阅物，不是地图字段、导入格式或工坊内的可执行预览。工坊仍以共享 `MapExplorer`
  预览经 Schema 校验的 JSON。
- 地图导入复用 `MapEntrySchema` 与 SVG 安全边界，非法结构或 SVG 不得修改草稿。
- 提示词以当前地图作为修改基线；未被修改要求点名的字段和节点必须保留。

## Agent 分工

- 主 Agent：提示词契约、界面接入、导入状态流、测试与 Spec 收口。

## 验收标准

- 地图目录可发起 AI 新建，当前地图可发起 AI 修改。
- 下载提示词逐项解释所有正式地图字段，说明坐标数组的区间语义与节点层级相对坐标，并给出安全 SVG 白名单和禁止项。
- 提示词要求先按需访谈，可输出自包含 HTML 供审阅；作者确认后最终仅输出完整 `MapEntry` JSON。
- 新建导入合法 JSON 后生成未保存草稿；修改导入后保留当前 UUID。非法 JSON 或不安全 SVG 显示错误且不改变草稿。
- 角色 AI 流程与既有地图 JSON 文件往返不受影响。

## 测试所有权与验证范围

- 定向测试覆盖地图提示词字段解释、HTML 审阅阶段、当前地图注入、完整 JSON 解析及恶意 SVG 拒绝。
- 执行创意工坊验证脚本、相关 Prettier/ESLint 和 development webpack 构建。
