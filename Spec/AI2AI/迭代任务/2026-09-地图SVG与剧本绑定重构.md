# 2026-09 地图 SVG 与剧本绑定重构

## 状态

自动化验收完成待宿主验收

## 目标与范围

- 地图节点的 `图标` 改为完整 SVG 字符串，使外部 AI 可依据风格示例自由生成图标，不再依赖预定义图标名称。
- 将尘史使徒现有地图界面抽为运行时、地点选择和只读预览共用的权威组件，创意工坊直接复用。
- 创意工坊开放地图资产管理，但只允许通过 UTF-8 JSON 导入、覆盖导入与导出编辑；不建立节点表单、拖拽编辑器或内置 JSON 文本编辑器。
- 剧本从项目唯一地图自动关联改为显式选择一个地图 UUID，并在更换地图时校验初始 `地图索引`。
- 同步更新 Beta `配置/地图.json` 和 `更新规则/（配置1）世界编辑任务.ini`，使存量地图及运行时新增节点都生成完整 SVG。

## 关键设计决定

- 每个地图节点继续保留递归结构、描述、详情、方位和 `子地图`；仅把 `图标` 的语义从枚举名替换为完整 `<svg>` 字符串。
- SVG 由共享净化与渲染边界处理。仅允许静态 SVG 图形标签、安全属性和安全颜色，允许各元素分别着色；拒绝脚本、事件属性、`foreignObject`、外部资源、危险 URL 与输入中的可执行样式。渲染时将已校验颜色转换为内联 `!important`，抵抗宿主样式覆盖。
- 地图注册表允许多张地图；`ScenarioEntry.内容配置.地图` 继续保存单个地图 UUID，不改剧本外部字段形状。
- 工坊地图 JSON 往返使用完整 `MapEntry` 对象；覆盖导入保留当前地图 UUID，所有导入先校验、再确认、后进入既有草稿与原子保存流程。
- 地图预览、剧本初始地点选择与尘史运行时必须消费同一地图组件和同一 SVG 渲染器，通过模式控制操作能力。
- 存量 Beta 地图一次性迁移为内嵌 SVG；世界编辑提示词提供风格约束与示例，但不再提供图标枚举。

## Agent 分工

- 主 Agent：任务定界、权威路径审阅、跨模块整合、Spec/API 收口与最终验证审阅。
- 地图与工坊实现 Agent：共享地图组件、SVG 安全边界、多地图加载、地图 JSON 往返和剧本绑定实现及实现自测。
- Beta 配置 Agent：迁移 `地图.json`，更新世界编辑任务中的地图图标规则、示例和新增节点协议，并执行 JSON/文本自检。
- 独立测试 Agent：从本任务验收标准补充或审阅验证脚本，执行工坊、剧本组装、构建与定向静态检查。

## 验收标准

- 任意合法地图节点可携带完整 SVG 并在尘史运行时、工坊预览和初始地点选择中一致显示；不再通过图标名称映射路径。
- SVG 中的脚本、事件处理器、外部链接、`foreignObject` 和危险 URL 不会进入渲染 DOM；非法 SVG 导入失败且不污染草稿。
- 创意工坊可创建地图草稿、覆盖导入当前地图和导出完整 `MapEntry` JSON，并可预览但不能通过表单修改节点。
- 地图注册表可包含多张地图；剧本编辑器可显式绑定其中一张，并显示真实预览。
- 剧本未绑定地图、绑定 UUID 不存在或初始 `地图索引` 不存在于所选地图时不可玩并给出明确原因；更换地图不静默改写初始地点。
- 资产包选择、依赖闭包、冲突复制和 UUID 重映射继续正确处理剧本到地图的单例引用。
- Beta 存量地图所有节点的 `图标` 都是合法、安全且保留原 path 造型的完整 SVG；世界编辑任务要求新增节点同样输出完整 SVG，并允许克制的多色设计。
