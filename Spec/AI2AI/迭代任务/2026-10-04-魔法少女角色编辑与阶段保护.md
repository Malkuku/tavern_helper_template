# 魔法少女角色编辑与阶段保护

状态：本地实现与行为验证完成，待宿主联调。

## 目标与范围

魔法少女手机角色资源编辑器补齐现有角色结构的可视化字段，替换当前剧情时避免默认重置人设阶段。尘史创意工坊使用不同角色契约，不改其数据结构。

## 设计与责任

- `roleAssets`
  负责运行态替换规则：默认保留已有完整人设阶段；作者显式选择后才用资源阶段替换。新增角色继续使用资源或次要角色通用模板。
- 保存资源与写入剧情继续分开；替换确认展示真实结果，阶段范围不兼容时报告错误。
- 编辑器按领域组织固定表单，补齐阶段、身体、身份检索词、魔法形态与能力限制；完整 JSON 保留为高级入口。
- 当前 Agent 负责设计、实现、自测与收口，不设置独立验收角色。

## 验收与验证

- 已发展角色默认替换后，阶段等级、经验、全部描述保持原值；显式替换才使用资源值。
- 新增角色、次要角色模板、取消、保存冲突与回滚继续有效。
- 真实 Vue 组件事件覆盖阶段编辑与原位字段修改；资源保存重读保留改动。
- 定向角色脚本、ESLint、格式检查与开发构建。
