# 2026-09 剧本 JSON 往返与导出选择器整改

## 状态

自动化验收完成待宿主验收

## 目标与范围

- 重绘“辉光学徒”与“长路归乡”当前使用的灯、冬共享 SVG 图标，提高小尺寸与剧本卡尺寸下的辨识度。
- 开发者剧本工作台提供单个剧本纯 JSON 导入和导出，不再把单剧本导出伪装成资产包。
- 整理用户工作区的选择导出界面，并把所选剧本的角色、地图和共享资源依赖实时显示为自动勾选。

## 关键设计决定

- 图标继续由 `ScenarioIconPaths` 作为唯一来源，所有剧本卡和工坊入口自动复用。
- 资产包的依赖闭包仍以 `expandPackageSelection` 为权威；选择器只投影其结果，并区分手选与自动关联，不复制引用规则。
- 单剧本 JSON 使用完整 `ScenarioEntry`
  对象。导入针对当前选中剧本执行确认后的整体覆盖，保留当前 UUID，经过既有 Schema 校验和差异审阅/保存流程，不直接写世界书。

## Agent 分工

- 主 Agent：设计、实现、实现自测、自动化验收与 Spec 收口。
- 本轮不设独立测试 Agent；补充现有工坊验证脚本并执行最小构建验证。

## 验收标准

- 灯图标呈现灯笼、内焰和放射辉光；冬图标呈现远路、地平线与归家灯火，在 38px 目录尺寸仍可辨认。
- 剧本可导出为不含资产包包装层的 UTF-8
  JSON；合法 JSON 可在明确确认后覆盖当前剧本草稿且 UUID 不变，非法或非剧本 JSON 给出明确错误且不修改草稿。
- 勾选剧本后，其依赖项立即呈现已勾选和关联来源；取消剧本后不再被其他已选剧本依赖的项目恢复普通状态，手选项目保持选中。
- 导出弹窗具备清晰的摘要、分类层级、资产说明、手选/自动关联状态和移动端布局。
