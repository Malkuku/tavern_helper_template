# 手机桌面布局与按需初始化

状态：已完成；待宿主视觉与 MVU 时序联调。

## 目标与范围

- 每次打开手机时检查主世界书并合并当前楼层变量；聊天切换只清理旧数据，不抢先初始化。
- 手机桌面图标支持拖拽排序、移入/移出文件夹，布局保存在手机脚本变量中。

## 关键设计

- `App.vue` 打开手机时调用 Store 的 `checkWorldbook()`；Store 使用序号取消过期异步检查，并在读取世界书后才读取最新 MVU 楼层。
- 脚本变量 `magicGirlPhoneLayout` 是桌面与 Dock 布局的唯一持久化来源，布局不写入 `stat_data`。首次使用采用当前默认排列；新增应用补到桌面，失效应用忽略。
- 图标拖到另一图标中心创建文件夹，拖到文件夹加入；拖到图标边缘或空白处调整顺序。文件夹内可打开应用并将图标移出。
- 保留现有手机视觉与应用入口。脚本变量读写失败时保留当前内存布局并报告错误。

## 分工、验收与验证

- 单 Agent：实现打开时检查、布局模型、拖拽交互、脚本变量适配与文档。
- 验收：重复打开都会检查；聊天切换不提前写入；拖拽排序及创建/加入/移出文件夹生效，关闭再打开布局不丢；原应用均可进入。
- 定向行为测试布局变换与无效保存数据；构建、ESLint、Prettier 检查相关文件。宿主视觉与 MVU 时序仍需真实环境联调。

## 文档更新

修订世界书初始化 API 契约、手机架构说明及索引。取缔旧的脚本启动/聊天切换即初始化触发点。

## 完成记录

- 打开手机时调用主世界书检查，聊天切换只取消旧检查并刷新读取状态。
