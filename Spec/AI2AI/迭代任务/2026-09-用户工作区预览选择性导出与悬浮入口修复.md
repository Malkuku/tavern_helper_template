# 2026-09 用户工作区预览、选择性导出与悬浮入口修复

## 状态

自动化验收完成待宿主验收

## 目标与范围

- 用户工作区的待加入角色可先查看结构化档案，再决定加入或替换。
- 资产包导出允许按资产选择；被选剧本所引用的资源自动纳入导出包。
- 创意工坊悬浮入口可在鼠标和触摸设备上实际拖拽，并明确展示“创意工坊”身份。

## 关键设计决定

- 角色预览复用现有角色数据与头像，不创建另一份详情数据模型；加入与替换仍走既有原子写入路径。
- `createPackage` 是导出依赖闭包的权威责任点，界面只提交显式选择，避免调用方遗漏剧本依赖。
- 悬浮入口使用 Pointer Events 在宿主视口内定位，不再依赖零尺寸挂载点下的 jQuery UI containment。

## Agent 分工

- 主 Agent：设计、实现、实现自测、Spec 收口。
- 本轮不设独立测试 Agent；依据现有验证脚本补充自动化断言并执行最小构建验证。

## 验收标准

- 角色卡可打开预览，预览显示身份、外貌/简介、背景、性格、技能/术、状态与物品等已有信息，并可从预览执行加入或替换。
- 导出弹窗可按分类与具体资产勾选；空选择不能导出；选择剧本时包内自动包含其全部直接引用资源。
- 悬浮入口有明确文字标识；拖动后不会误触打开，位置被限制在可见视口内，鼠标与触摸共用同一路径。
