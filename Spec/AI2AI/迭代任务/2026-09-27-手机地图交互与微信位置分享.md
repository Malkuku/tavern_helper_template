# 手机地图交互与微信位置分享

状态：实现与定向验证完成；宿主触屏和视觉待联调。

## 目标与范围

- 手机地图恢复滚轮、双指缩放和拖动；压缩顶部文字，扩大地图可见区域；单击节点看详情，双击进入子地图。
- 微信消息支持以正式地图节点 key 表示的位置卡片；点击卡片打开地图并定位节点。微信扩展面板中的位置入口可发送节点 key。
- 后台与主动聊天规则说明位置标签、key 来源和生成约束。

## 关键决定

- 沿用 `layoutPhoneMap` 与共用节点避让，交互缩放和平移只作用于手机地图视口，不改写地图数据。
- 位置消息采用 `<位置 key="地图节点key">`，key 必须精确存在于当前 `stat_data.地图`；地图内仍以节点 key 查找路径，显示名和当前位置不代替 key。
- 手机应用壳传递一次地图打开请求。找不到 key 时卡片仍显示，但给出明确错误，不跳到错误地点。
- 地图搜索和微信定位在相同的层级导航上工作。

## 分工与验收

- 当前 Agent：实现、规则与契约更新、定向验证和文档收口；无独立测试 Agent。
