# 微信账号管理与图片分类

状态：实现与本地验证完成；待宿主触屏、脚本变量及视觉联调。

## 目标与范围

- 重做“我 → 设置 → 账号管理”的信息布局。管理页展示当前楼层全部微信账号及尚未建号的主要、次要角色，含未发现角色；角色选择不依赖目标发现状态。未建号角色可在管理页显式创建微信账号。
- 图片库显示现有图片缩略图、引用标识和引用状态，可直接复制引用、选为当前账号头像或表情包。
- 图片库支持自定义一级与二级文件夹，把图片分配到文件夹；文件夹只影响浏览分类，不改变图片 URL、图片内容和账号引用。

## 关键设计决定

- `stat_data.手机.微信.账号` 仍是账号、好友和媒体引用的唯一权威来源；图片内容仍由脚本变量 `magicGirlWeChatImageLibrary`
  保存。
- 新的脚本变量 `magicGirlWeChatImageCategories`
  只保存文件夹名称、层级与图片 ID 到文件夹的归属。未归类图片自动出现在“未分类”；删除图片时清理其分类记录。
- 管理页顶部为可搜索的账号与角色列表，未建号角色明确标记并可显式建号；资料和图片库为同页切换区，当前选择一直可见。
- 图片引用仍为
  `script-image://<图片ID>`；上传、分类、移动或重命名文件夹均不改变引用。复制引用和选用图片都从同一图片库数据读取。
- 原有下拉账号框、藏在表单末尾的图片库列表与手填库内 URL 的主路径退出。外部 URL 仍可作为账号头像或表情包的兼容输入。

## 验收标准

- 进入管理页后可看到当前聊天的全部账号和角色；输入搜索词后仍能找到未发现、未建号的角色，并可为其创建账号再编辑。
- 图片库为空时有明确空态；有图时缩略图、引用和引用状态可见，复制得到原始 `script-image://` URL。
- 从图片库选图后可以保存为当前账号头像或表情包；重开后仍显示，其他账号引用同一图片不受影响。
- 可以创建、改名、删除一级和二级文件夹并移动图片；重新打开管理页分类仍在。旧图片默认落在未分类，移动和改名后原 URL 不变。删除文件夹只把其中的图片移到未分类或上一级，不删图片。
- 清理图片仍拒绝已被当前账号或媒体备份引用的图片；清理成功后分类记录同步清除。
- 手机窄屏内无横向溢出，账号列表与图片网格可滚动，密码门禁和返回路径保持可用。
