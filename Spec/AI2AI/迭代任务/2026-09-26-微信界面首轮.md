# 微信界面首轮

## 状态

已完成

## 目标与范围

在现有手机浮层中增加微信桌面入口，复刻微信的四个主标签、会话列表、会话详情与本地消息输入。当前没有宿主通信契约，界面使用明确的本地演示数据。

## 关键设计决定

- 保留手机壳子、控制中心和其他应用占位页，微信作为独立 Vue 组件接入现有应用入口。
- 微信组件独立维护标签、所选会话和本地消息；退出微信后重新打开时重置演示状态。
- 可见的导航与按钮必须有实际本地动作；尚无数据契约的能力不展示成可执行功能。
- 视觉以微信常见的浅灰页面、白色列表、绿色强调与底部四标签为基线。

## Agent 分工

- 当前 Agent：设计、实现、自测、文档收口；本轮不设独立验收角色。

## 验收标准

- 桌面微信入口可打开微信首页并返回桌面。
- 四个标签可切换；会话可进入、返回并发送本地文字消息。
- 微信界面在手机尺寸及移动端全屏视口内正常滚动，状态栏和底部操作区不遮挡主要内容。
- 其他应用、控制中心和手机窗口行为保持可用。

## 测试所有权与验证范围

- 真实酒馆宿主视觉验收仍需在宿主环境进行。
