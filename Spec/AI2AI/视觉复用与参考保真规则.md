# 视觉复用与参考保真规则

## 适用范围

当需求使用“复用现有视觉”“与某页面一致”“真实预览”“保持原样”“参考现有组件”等表述时，本规则为强制工程约束，适用于正式页面、创意工坊、预览、设置摘要及运行时视图。

## 权威实现

- 被指定的既有页面或组件是视觉与交互基线，不是重新设计邀请。
- 同一业务对象在多个入口展示相同视觉时，必须抽取或扩展权威共享组件，让各入口直接消费同一 DOM、样式、图标与主题效果。
- 配置注册表只保存标识和到权威资源的映射，不得并行维护另一套颜色、阴影、图标 path、CSS class 或近似结构。
- 预览必须渲染正式组件；静态色块、截图、重画卡片和“看起来差不多”的 CSS 不属于真实预览。

## 禁止事项

- 禁止把原组件 CSS 复制到消费页面后声称复用。
- 禁止在没有用户明确授权重新设计时，自行替换已存在的色彩、图标、动效、布局和视觉层级。
- 禁止新建 wrapper 后仍让各入口保留各自视觉实现。
- 禁止用共享数据或共享 token 代替组件级复用；若 DOM 和视觉规则仍然分叉，职责尚未收敛。
- 禁止仅凭构建成功宣称视觉一致。

## 实施与验收

1. 开始前定位原页面的 DOM、样式、图标、动效及状态分支。
2. 明确唯一权威组件和允许由 props/slot 变化的内容。
3. 原页面自身也必须改为消费共享组件，避免“原页面一套、预览一套”。
4. 删除消费入口中的重复 CSS、图标表和近似组件。
5. 自动化检查所有目标入口导入权威组件，并阻止主题样式重新出现在消费页面。
6. 真实宿主或视觉截图验收应比较同一数据、同一状态下的布局、颜色、图标和动效。

## 当前权威路径

- 剧本卡视觉：`src/尘史使徒/UI/components/scenario/ScenarioVisualCard.vue`。
- 剧本方案映射：`src/创意工坊/scenario/themes.ts`，只映射中文方案标识到原主题 class 和共享图标白名单。
- 消费入口：尘史开场设置、尘史设置页、创意工坊剧本视觉选择与预览。
- 任务/事件卡视觉：`src/尘史使徒/UI/components/task/NarrativeEntryCard.vue`；运行时道寻页与创意工坊叙事编排共同消费。
- 主线完成品视觉：`src/尘史使徒/UI/components/task/MainlineBlockRenderer.vue`；工坊画布和运行时道寻页共同消费 `主线.meta` 组件树，`MainQuestCard.vue` 只承载外框和旧数据兼容。

本规则源于同类“近似重画代替真实复用”问题累计出现四次。后续涉及现有视觉复用时，任务文档和验收标准必须显式引用本规则。
